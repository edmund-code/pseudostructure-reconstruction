## What the paper actually does (from the full text)
- Model / statistic: order-3 tensor Y_ijt (subject i, feature j, time t in subject-specific set T_i), approximate CP decomposition Y_ijt = sum_l lambda_l a_i b_j xi_l(t) + Z (eq. 1). The temporal loading xi_l(t) is ONE smooth function per component shared by all subjects and features; a subject enters only through a scalar loading a_i per component. Smoothness via an RKHS penalty (Bernoulli-polynomial kernel), xi fitted by kernel ridge regression; components estimated sequentially by least squares (eq. 5-14). Optional "mean subtraction" removes the first singular component of the subject x feature time-averaged matrix (time-invariant structure) before decomposition; used in all analyses (Methods "TEMPTED algorithm").
- Input: any user-chosen transformation; for microbiome, CLR with pseudocount 0.5 (eq. 4). Least-squares loss, no count likelihood (Methods "Microbiome data preprocessing"; Add. file 1 Fig. S3 legend: TEMPTED minimises an l2 loss on CLR data).
- Outputs: subject loadings (subject-level beta diversity, classifiers), feature loadings, temporal loadings, per-subject aggregated trajectories (eq. 2: feature-loading-weighted sum), and log-ratio trajectories of top vs bottom features (eq. 3).
- Null / calibration / significance: none built in. Phenotype separation is assessed afterwards: Wilcoxon rank-sum on subject loadings (Fig. 3d,g; Table S2), PERMANOVA on sample-level distances (Fig. 2b; Table S1), logistic regression / random forest AUC-PR with leave-one-out or out-of-bag (Fig. 2a,c).
- Replicates: subjects are a tensor mode; irregular, subject-specific time points handled without binning or imputation. Cannot handle missing individual entries in the tensor (Discussion), so every feature must be observed in every sample.
- Transfer: test subjects' loadings estimated with training feature and temporal loadings fixed, same features and same time frame required (Methods "Transfer of dimension reduction").
- Validation: data-driven simulations on ECAM (23 vs 17 infants, 2-9 samples per subject) and FARMM (10 vs 20 subjects, 15 days) against CTF, microTensor, FTSVD, TCAM, PCoA (Fig. 2); toy example with 3 groups of 20 subjects, 20 random times each (Add. file 1 S1); case studies Pax5 mice (17 WT, 27 Pax5+/-, 17 developed leukemia), vaginal 16S (141 term, 49 preterm), vaginal MAGs (111 term, 35 preterm) (Fig. 3).
- Plot types: temporal loading curves (Fig. 1c-e, 3a); subject loadings by phenotype with Wilcoxon P (Fig. 3b,d,g); ranked feature loadings (Fig. 3e,h); log-ratio trajectories of top vs bottom features per subject group (Fig. 3c,f,i); benchmark AUC-PR / PERMANOVA F curves (Fig. 2).
- Software: R package "tempted" on CRAN (GitHub pixushi/TEMPTED) and Python package "gemelli" (GitHub biocore/gemelli) (Data availability).
- Limitations the authors state: unsupervised, leading components need not capture the phenotype, and it does not "look for differential temporal trends between host groups"; smoothness makes it "unsuitable for change point detection"; cannot handle individual missing entries; sequential fitting does not give the best rank-r reconstruction (Discussion). Smoothness parameter C_K = 1e-4 worked "for most datasets ... with more than four time points"; fewer time points need larger C_K (Methods; Fig. S2).
- Limitations for OUR design: (1) Because the positional curve of a component is shared, specimens can differ only in amplitude/sign of a fixed shape; a shift in WHERE a program changes between species or conditions is not represented within a component. (2) Genes must be measured in every specimen (no missing entries): restrict to genes measured in both species. (3) No count model or offset; input must be normalised (e.g. log-normalised or residuals). (4) Smooth temporal loadings blur sharp S1/S2 edges. (5) The paper's smallest real cohort is 30 subjects; with 5 specimens the subject loadings are 5 numbers and no test applies.

## Fit to our design (revised)
Weak fit for our main question. It extracts shared positional shapes and ranks genes, but specimens differ only by a scalar per component, so the human-vs-mouse "where" question is not addressed, and it needs complete gene panels and pre-normalised data. Keep it as a minor alternative to MEFISTO, not a co-equal option.
