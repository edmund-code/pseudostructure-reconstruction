## What the paper actually does (from the full text)
- maSigFun: the maSigPro two-step regression (polynomial time terms, dummy variables for series, F-test with FDR, stepwise selection, R2 filter) fitted ONCE per functional class to the gene-wise standardized matrix of all its genes; "individual genes are considered as different observations of the expression profile of the class". Detects classes whose genes move together; simulations need about 70% co-expressed members; in real data it selected small classes (3-6 genes) with inner correlation about 0.6.
- PCA-maSigFun: PCA per class; keep components whose normalized explained variance exceeds the data-set mean gene variance (taken as the noise level); component scores become "synthetic genes" analysed by maSigPro; gene loadings (signed) with a bootstrap 95th-percentile threshold identify contributing genes. Usually 1-2 components per GO term, up to 3 for generic classes (ribosome, translation). Signed loadings show members acting in opposite directions in one pattern (acute-phase positive vs negative proteins, Fig 7; PIN efflux carriers, Arabidopsis).
- ASCA-functional: ASCA (ANOVA decomposition + SCA) submodels for time and treatment; genes ranked by their loading on a component; FatiScan gene set analysis on the ranked list; top-ranked sets follow the pattern, bottom-ranked follow the opposite.
- Null / significance: FDR 0.05 throughout (maSigPro F-test for maSigFun and for component scores; FatiScan for ASCA-functional).
- Replicates: replicate arrays per time point and series are observations in the regression (independent design); in maSigFun genes are also observations, so the class test treats member genes as independent replicates.
- Validation: two simulation studies (2 series x 3 time points; 250 classes of which 25 contain changing genes; class size 5-100; 20-80% co-expressed; 50 runs each): maSigFun needs about 70% co-expressed genes (depends on R2 cut), PCA-maSigFun detects any class with at least 20% changing genes (sensitivity and specificity near 1), ASCA-functional detects from 50-60%. Real data: rat bromobenzene toxicogenomics (2,665 genes, 5 series, 3 times), potato abiotic stress (4 series, 3 times, 3 replicates), Arabidopsis IAA (Affymetrix, 3 times, 2 doses). Compared with STEM (few or no significant GO terms after FDR) and a pairwise-difference GSA (Minguez).
- Plot types: class median profile beside all member profiles by series (Fig 5); score profiles of significant GO-components with loading plots and significance thresholds (Figs 6-7); ASCA component score plots (Figs 8-9); sensitivity curves from simulations (Figs 2-4).
- Software: R code at bioinfo.cipf.es/downloads (the paper does not say these are in the maSigPro Bioconductor package).
- Limitations stated: maSigFun favours small, tight classes and misses heterogeneous ones; PCA-maSigFun returns very large selections ("not ... an enrichment analysis strategy"; 447 of about 1,400 non-redundant GO terms in the potato data); ASCA-functional only sees the major trends.
- Limitations for OUR design: along PT nearly every pathway has at least 20% positional members, so PCA-maSigFun would select almost all of them; component retention uses a data-set-wide noise level that pooling specimens or species would distort; the regression treats bins (and, in maSigFun, genes) as independent observations.

## Fit to our design (2-4 lines, revised after reading the full text)
PCA-maSigFun's per-class PCA with signed loadings is a direct, published version of "check sub-trends before summarizing" and handles members moving in opposite directions (their acute-phase example). Use it per specimen on centred bins as a descriptive decomposition with loading plots; selection and significance must come from our competitive, specimen-calibrated tests, since its own test would pass nearly every PT pathway.
