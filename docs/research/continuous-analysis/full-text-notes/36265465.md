## What the paper actually does (from the full text)
- Model / statistic: for a "layered tissue", each gene's expression is a piecewise linear function of relative depth, with layer-specific intercept alpha and slope beta and breakpoints shared by all genes (eq. 1-4). Counts are Poisson with a library-size offset (a Gaussian alternative on normalised data is also given; Methods "Axis-Aligned L-Layered Problem"). Breakpoints and functions maximise the joint likelihood over all genes by dynamic programming, an extension of the classical segmented-regression DP (eq. 8-9). Curved layers: relative depth is the real part of a conformal map, computed by solving the heat equation between given approximate boundaries (finite differences on the Visium hexagonal grid). Linear boundaries: a second DP (Nussinov-like, eq. 15-19). Parallel lines: rotation sweep.
- In practice, breakpoints are found by running the Gaussian DP on the top 2L GLM-PCA components (100x faster), then per-gene Poisson regressions are fitted within each layer (Methods "Improving run-time"; Proposition 2 shows the mean matrix has a rank-2L piecewise-linear factorisation).
- Number of layers L: elbow of the consecutive differences of negative log-likelihood; the authors say AIC and BIC were "unhelpful" (Methods "Data processing and parameter selection", Supp. Fig. S14).
- Null / calibration / significance: none. Genes are RANKED (max layer slope, slope in one layer, sum of absolute slopes, max boundary discontinuity, or an LRT p-value of piecewise linear vs piecewise constant used only as a ranking score; Methods "Additional approaches"). The Discussion lists "rigorous statistical testing ... e.g., using the Chow test" as future work. No breakpoint uncertainty.
- Replicates: none. Each slice is analysed alone (12 DLPFC slices from 3 donors are each scored separately by ARI).
- Validation: two simulations (synthetic piecewise-linear Poisson on a rotated grid; Splatter trajectories), layer recovery by ARI vs BayesSpace, SpaGCN, SCANPY, stLearn; DLPFC Visium (ARI; marker recovery by AUPRC, which is low for all methods, e.g. 0.032 vs SPARK 0.029, Fig. 4A); Visium mouse skin wound (ARI 0.633); Slide-seqV2 somatosensory cortex. The authors note the DLPFC Donor 2/3 comparison is "overly generous" because Belayer used the manual boundaries.
- Plot types: layer maps vs manual annotation (Figs 3D-E, 5B, 6A); binned expression (summed counts over relative-depth bins, log-normalised) vs relative depth with fitted piecewise lines and dashed layer boundaries (Figs 4B, 5C, 6B); ARI bars; precision-recall curves.
- Software: Python (sklearn PoissonRegressor, glmpca-py); code deposited at Zenodo, DOI 10.5281/zenodo.6970061 (key resources table). No GitHub URL is given in the paper.
- Limitations (authors): DP only for known approximate boundaries or straight-line boundaries; ~20 h on a 100-node cluster for the line DP on DLPFC; no statistical testing; only linear pieces; layered geometry only. Limitations for us: one sample, no specimen terms, no P values, L by elbow, Poisson not NB (overdispersion ignored); shared breakpoints are a transcriptome-wide segmentation, not a per-gene test.

## Fit to our design
Low-medium. Our axis is already 1-D, so only the axis-aligned segmented-regression DP is relevant, and that is classical (Bai-Perron). Belayer adds a joint, all-gene breakpoint search and the GLM-PCA shortcut, which could be used once as a descriptive check of where transcriptome-wide breakpoints fall relative to S1/S2/S3. It offers no testing, no NB, and no replicate handling.
