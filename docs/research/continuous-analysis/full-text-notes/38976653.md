## What the paper actually does (from the full text)
- Model / statistic:
  - Binning (2.1; Supp 1.1): pseudotime per path is cut into bins (Sturges by default; also square root, Rice, Doane, Scott, Freedman-Diaconis; drop factor k); counts are summed per bin (pseudobulk); the binned pseudotime used in the model is the ORDINAL BIN INDEX (Supp Fig. 1). Bin equalisation (2.2) splits bins larger than mean + SD of bin sizes and optionally drops bins smaller than mean - SD.
  - Poly-GLM (2.3; Supp 1.3): maSigPro polynomial in binned pseudotime with path dummy variables and path x time terms (cubic in all applications); default NB with log link; offset = log DESeq2 size factor per bin (estimateSizeFactorsForMatrix).
  - Two-step selection (2.4): full model vs intercept-only by likelihood ratio (sc.p.vector; supplement: BH-adjusted, 0.05); then stepwise regression drops non-significant terms (sc.t.fit); R2 (= deviance explained for GLMs) threshold selects genes (0.6 in benchmarks, 0.7 on real data).
  - Clustering: sc.cluster.trend calls maSigPro see.genes / PlotProfile; hclust, 6 clusters on real data (Supp 4.4.3). GO over-representation by clusterProfiler.
- Null / calibration: LRT p-values with BH; bins (not samples) are the observations. Benchmarks: TPR/FPR at R2 thresholds on Splatter simulations (2,000 genes, 3,000 cells, bifurcation; sparsity 60-90%, skew, unequal path lengths); vs tradeSeq patternTest/diffEndTest with iCOBRA (Fig. 2F): tighter FPR, TPR only marginally better; misses low-fold-change genes DE in one path only.
- Replicates: none in the model. The HSPC data (Setty 2019) has three donors; each donor gets its own trajectory and its own scMaSigPro run (2.8, Supp 4.3); Donor-1 = 195 cells, 6 + 3 bins (3.4).
- Real data: on HSPC the authors switched to a Gaussian family because Seurat cell-cycle regression had produced scaled continuous values (Discussion; Supp 4.4.1); so the NB+offset model was used only in simulations.
- Plots: cluster trend profiles per path (Fig. 3A), fitted polynomial vs binned values per gene (Fig. 3B), ROC curves.
- Software: R package scMaSigPro (GitHub BioBam/scMaSigPro; Zenodo 12568922).
- Limitations stated: TPR falls when path lengths differ >2-fold; >80% zero inflation needs imputation; misses small one-path changes. For OUR design: bins replace position with an ordinal index; cubic polynomials cannot represent sharp edges; no specimen term.

## Fit to our design (2-4 lines, revised after reading the full text)
The closest single-cell analogue of our binned pseudobulk with a size-factor offset, but with bins as observations and no specimen term. The group x polynomial-term decomposition (offset, slope, curvature differences) is an easy-to-read contrast set we could fit on specimen-level binned profiles; low polynomial degree and ordinal bin indices make it unsuitable for locating edges.
