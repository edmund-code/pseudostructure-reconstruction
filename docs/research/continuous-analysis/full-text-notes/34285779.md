## What the paper actually does (from the full text)
- Model / statistic: for each cell, rank all genes by expression; ranks beyond r_max (default 1,500, chosen to match typical minimum-genes QC thresholds) are set to r_max + 1 to cut the long tail of zeros. The UCell score of a signature is a normalized Mann-Whitney U computed from the signature genes' ranks in that cell (Methods). It is closely related to the AUC, so it is expected to correlate with AUCell.
- Null / calibration: none; it is a descriptive per-cell score.
- Replicates: none; cells are the units.
- Validation: one human blood T-cell CITE-seq dataset (Hao et al.). A two-gene CD8 signature gives identical UCell score distributions for CD8 T cells whether scored in the full dataset or the CD8 subset, while Seurat's AddModuleScore shifts from a median of about 1 to about 0 (Fig. 1C-D), because AddModuleScore bins genes by their average expression across the whole dataset. UCell is about 3x faster than AUCell and uses far less memory (5.5 GB vs > 64 GB at 100,000 cells; Fig. 1E-F). No benchmark of accuracy, of dependence on detected-gene count, or of noise.
- Plots: UMAP overlays of signature scores (Fig. 1B); score distribution comparisons (Fig. 1C-D); runtime and memory curves (Fig. 1E-F).
- Software: R package UCell, https://github.com/carmonalab/UCell (Seurat integration); demo code https://gitlab.unil.ch/carmona/UCell_demo. No Python version in the paper.
- Limitations for us: the 1,500-rank cap means members that are not among a unit's top ~1,500 genes all tie, so low-expressed pathway members contribute nothing; with aggregated tubule units the detected-gene count (and so ranks) varies with unit size; species-specific panels change the gene universe that is ranked.

## Fit to our design (2-4 lines, revised after reading the full text)
A fast, composition-independent per-unit score; the right kind of score if we ever want unit-level pathway activity before fitting per-specimen curves. The rank cap and the dependence on detected-gene count make it worse than count-model curves for low-expressed members, and it gives no inference. Its main value for the review is the evidence that AddModuleScore-type scores depend on the pool.
