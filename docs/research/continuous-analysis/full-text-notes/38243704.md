## What the paper actually does (from the full text)
- Model / statistic: two steps. (1) Take pre-computed spatial clusters (manual annotation, BayesSpace, StLearn). (2) Per gene, edgeR NB GLM on SPOT-LEVEL counts: mean = effective library size (total count x TMM factor) x exp(cluster coefficient); gene-specific dispersion "modeling the variability between spots". Global SVG test = LRT that all cluster coefficients are equal (one test across all clusters). Individual-cluster test = LRT on each cluster coefficient, to find the region driving the signal (Methods "Inference with DESpace").
- Multiple samples: a sample-specific coefficient gamma_gj (fixed effect, first sample baseline) is added to the mean; SVGs are still tested on the cluster coefficients (eq. 4). The cluster effect is shared by all samples; there is no sample x cluster random effect, and spots remain the units of the test. The authors contrast this with spatialLIBD's pseudobulk limma, which "requires biological replicates", whereas DESpace "models individual (spot-level) measurements" and "does not require biological replicates" (Introduction).
- Null / calibration: semi-simulations built by re-arranging real counts (Giotto pattern simulation) on LIBD Visium, melanoma ST and Slide-seqV2 cerebellum; FDR and TPR vs nominal; raw P-values of uniform genes are approximately uniform (Supp. Fig. S4). In the multi-sample simulation the SVGs and their patterns were made "consistent across samples", so between-sample variation of the spatial pattern was not simulated (Results "Simulation studies-multiple samples").
- Findings: DESpace controls FDR and has the highest TPR, especially with 3+ clusters; SPARK (cerebellum) and Seurat FindAllMarkers inflate false positives; SpatialDE and nnSVG are conservative (P-values pushed toward 1). On real data DESpace calls more SVGs than any other method at 1% FDR. Top-gene coherence across replicates by Jaccard index (Fig. 6).
- Plot types: spatial cluster maps (Fig. 1); simulated pattern maps (Fig. 2); TPR-vs-FDR curves (Figs 3, 5); expression maps with the tested cluster outlined (Fig. 4); Jaccard bars (Fig. 6). No logFC-per-cluster plot is shown in the main text.
- Software: R/Bioconductor DESpace; analysis scripts github.com/peicai/DESpace_manuscript, Zenodo 10.5281/zenodo.10481110.
- Limitations (authors): needs pre-computed clusters; misses patterns that do not follow clusters; double dipping when clusters come from the same data (argued to be marginal empirically); targets global patterns. Limitations for us: with specimens as replicates, the spot-level NB test with a fixed sample intercept treats units (spots, or our tubule cross-sections) as independent replicates of the cluster effect, so it ignores between-specimen variation in the S1/S2/S3 pattern. With 2 specimens per group that is pseudoreplication; P values would be too small for a population claim.

## Fit to our design
Medium as a comparator template, low as a ready tool. The model form (NB GLM on discrete labels with a library offset and specimen intercepts, global LRT plus per-label tests) is exactly the discrete counterpart of our continuous NB test. The inference must be done at the specimen level (relabeling or pseudobulk), or the comparison "continuous beats discrete" will rest on two equally pseudoreplicated tests.
