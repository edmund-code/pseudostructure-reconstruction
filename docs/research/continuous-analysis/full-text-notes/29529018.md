## What the paper / package does (abstract + README + code; NOT the paper's full text)
- Model / statistic (README, code): input is an expression matrix and a pseudotime per trajectory, scaled to [0,1]. (1) Interpolate each gene to N (default 200) evenly spaced points using Gaussian weights exp(-d^2/winSz^2), winSz default 0.1, with an interpolation-error estimate (interWeights.R). (2) Optionally scale each gene's interpolated curve to [0,1] by min-max within each trajectory (scaleInterpolate.R; "Recommended"). (3) Dissimilarity matrix between interpolated points of query and reference in gene space (Euclidean by default), normalized to [0,1]; global alignment = DTW with step pattern symmetric2 from start to end of both trajectories; local alignment = search restricted to a thresholded region, returning the longest conserved stretch. (4) mapRealDataGlobal maps the warp back to cells; plotAlign / plotMapping figures. (5) pseudotimeClust: global alignment per gene, then k-means of per-gene pseudotime-shift profiles.
- Null / calibration: none in the code. The README example passes sigCalc/numPerm arguments, but the current globalAlign function has no significance calculation.
- Replicates: none; one reference trajectory vs one query.
- Validation (abstract and figure titles only): applied to mouse and human preimplantation embryo trajectories; a validation figure on scRNA-seq; the README example is mouse dendritic cells stimulated with LPS vs PAM (GSE48968), using a 99-gene LPS-induced module for global alignment and an 89-gene module for local alignment. Validation details, sizes and results are not available to us.
- Plots (README): dissimilarity matrix with the optimal path (plotAlign); pseudotime mapping between trajectories (plotMapping); example interpolated gene with error bars; mean interpolated expression with conserved points marked (local alignment).
- Software: R package from GitHub (devtools::install_github("shenorrLab/cellAlign")); README says tested on Windows 10 only; academic licence, commercial use needs a licence from the Technion.
- Limitations for us: min-max scaling removes amplitude as well as level and stretches flat, noisy genes to the full range; global alignment forces both trajectories to cover the same start and end (a partial human PT would be stretched); no uncertainty or replicate-level test.

## Fit to our design (2-4 lines, revised after reading README + code only)
A simple, transparent warp estimator for human-vs-mouse PT and a good figure (mapping plot). It has no replicate model or test, and its min-max scaling and end-to-end constraint need care with our panels and with unequal PT coverage. Paper-level claims beyond the abstract remain unverified.
