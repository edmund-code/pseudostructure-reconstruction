## What the paper actually does (from the full text)
- Model / statistic:
  - Binarisation (preprint 2.1, Fig. 1a-i): ONE GLOBAL threshold read off a histogram of all genes in all cells. The README (I-1) and, per WebFetch, the journal version instead fit a two-Gaussian mixture PER GENE (threshold where the two fitted Gaussians cross; Gaussian noise sd 0.1 added first; genes without a bimodal on/off distribution are dropped). The global threshold (default 0.2 on log-normalised data) remains an option.
  - Logistic regression of on/off state on pseudotime per gene; switching time = pseudotime where fitted P(on) = 0.5; fit quality = McFadden pseudo-R2 (preprint 2.2, Fig. 1a-ii). README: zero expressions can be randomly downsampled before the fit (for zero-inflated genes).
  - Gene filtering (README I-3): >90% zeros, FDR > 0.05, pseudo-R2 < 0.03 removed; top genes by pseudo-R2 plotted.
  - Pathways (README I-4): hypergeometric over-representation of MSigDB hallmark/C2/C5 sets among switching genes (pseudo-R2 cutoff 0.1, FDR 0.05); a pathway's switching time = MEDIAN switching time of its member switching genes; redundant pathways merged (overlap 0.8). The preprint itself only says it plots "the density of switching genes from each ontological class" for "significantly over-represented functional ontologies" (2.3, Fig. 1e); the median rule is in the README only.
  - Two trajectories (preprint 2.4; README Part II): common switching genes and their times; distinct switching genes per path; optional rescaling of both timelines to 100 bins (README).
- Null / calibration: per-gene logistic-regression p-values with FDR (README); hypergeometric FDR for pathways. No uncertainty on switch times or pathway times. Cells are the observations.
- Replicates: none modelled. One trajectory (or two paths) of cells.
- Validation: one example dataset (hESC to cardiomyocyte, Friedman 2018; README subsamples 3,000 cells; Monocle2 trajectory). No simulation, no benchmark in the preprint.
- Plots: switching timeline (genes at switch time; up above, down below the axis; Fig. 1a-iii, 1c, 1g); density/ridge plot of switching genes per over-represented ontology ordered by switching time (Fig. 1e; README "pathway ridge plots"); common-gene comparison plot (README).
- Software: R package GeneSwitches, GitHub SGDDNB/GeneSwitches (preprint gives https://geneswitches.ddnetbio.com).
- Limitations: authors state none. For OUR design: binarisation suits sparse single-cell data, not aggregated probe counts with an exposure offset; logistic P(on) has no NB count model, no specimen term, no interval on switch time; transient (peak) genes cannot be represented by one monotone logistic.
