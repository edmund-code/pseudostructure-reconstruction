## What the paper actually does (from the full text)
- Model: Monocle (v1) orders cells: expression in gene space -> ICA dimension reduction -> minimum spanning tree on cells -> longest path (diameter) through the MST = main trajectory; off-path cells form sub-trajectories (branches). Pseudotime = distance along the path (Results, Fig. 2a,b).
- Gene test: "we modeled each gene's expression as a nonlinear function of pseudo-time"; 1,061 genes dynamically regulated at FDR < 5% (Results). Model details (spline, tobit/VGAM family, LRT vs reduced model) are in the unread methods.
- Null / calibration: FDR < 5% (Benjamini-Hochberg implied); cells are the observations. Robustness: subsampling to as few as 50 cells kept Spearman >= 0.8 with the full ordering and >= 95% precision for dynamic genes (Fig. S7, described in Results).
- Replicates: none modelled. One cell line (primary human skeletal myoblasts), 4 time points, 50-100 cells each (Fluidigm C1).
- Clustering: genes clustered by "direction and timing" with k-means into six trends; GO terms and TF motif counts per cluster (Fig. 3). Transient clusters were found that bulk time-course RNA-seq missed (Fig. S9).
- Validation: concordance with known myogenic markers (cell-cycle early, sarcomere late), immunofluorescence frequencies of MEF2C/MYH2, subsampling; shRNA screen of 11 TFs (Fig. 4).
- Plots: ICA scatter with MST and diameter path (Fig. 2b); pseudotime-ordered heatmap of DE genes (Fig. 2c); marker kinetics by collection time vs pseudotime (Fig. 2e,f); k-means cluster panels with cluster mean in red and an exemplar gene, GO and TF columns (Fig. 3).
- Software: R, http://monocle-bio.sourceforge.net/ (as stated).
- Limitations stated: none formal. For us: cells as replicates; MST ordering is noise-sensitive (Monocle 2 later replaced it, PMID 28825705); the test machinery is a per-gene spline LRT without sample effects.
