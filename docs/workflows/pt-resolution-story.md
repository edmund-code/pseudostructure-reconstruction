# PT resolution story

`analysis/notebooks/14_pt_paper_figures_resolution_story.ipynb` builds an exploratory figure story from notebooks 12 and 13 saved results. Its main sequence is whole PT → S1/S2/S3 → continuous shared PT position. It checks whether broad species differences are retained, identifies discoveries added by the controlled discrete-to-continuous comparison, and shows where selected pathway and gene patterns lie along the coordinate. It does not refit expression models, recompute coordinates, rerun DESeq2, or rerun matched-null inference.

Run the generated mirror in the analysis environment after notebooks 12 and 13 have written their artifacts:

```bash
python analysis/pt_paper_figures_resolution_story.py --results-root results
```

The `PSEUDOSPACE_RESULTS_ROOT` fallback is supported. Plots, tables, and source data are written under `pt_paper_figures_resolution_story/` within the results root; keep these private outputs outside Git. The working notebook retains its rendered outputs. Use the output-free staging-copy workflow in `AGENTS.md` when staging notebook changes.

The broad-signal panel compares whole-PT DESeq2 gene statistics with the signed GAM-level Z statistics. The saved run shows Spearman ρ = 0.989 and 97.2% directional agreement. This is a preservation check for this dataset, not evidence that the methods are equivalent in general.

The main resolution benchmark compares the controlled discrete and continuous total-difference screens using the same common gene and pathway universe, expression scale, specimen adjustment, baseline, matched pathway test, and per-method BH rule (positive effect and q ≤ 0.05). The current saved run reports 66 discrete discoveries, all 66 retained by the continuous screen, and 23 additional continuous discoveries. These are saved-run descriptive counts: the notebook checks them against the detailed comparison table and manifest and stops if inputs change the calls. `source_data/controlled_pathway_calls.csv` contains all calls and `source_data/controlled_continuous_added.csv` contains the exact added set with pathway names, effects, q-values, and incremental-position support. The paired q-value panel shows every member of that saved added set. Do not describe native signed-GSEA `Spatial only` terms as these 23 controlled additions, and do not claim general power superiority from this cohort comparison.

The main positional examples include citrate cycle as a conventional-plus-spatial context example and three controlled-added flagships: glycolysis/gluconeogenesis, amino-acid transport, and mitochondrial fatty-acid oxidation. Each flagship must pass both the controlled-added call and the saved robust spatial evidence gate; the notebook stops if a call, program assignment, or redundancy check changes. Other originally reviewed pathway examples remain available in the detailed figure outputs, but they are not substituted for the controlled-added set.

For the original examples and all three flagships, the notebook exports signed gene-Z heatmaps with up to 15 measured pathway members, selected by `T_spatial` and ordered by peak absolute-Z position. Display colors are clipped at ±6; `source_data/signed_heatmap_and_fit_values.csv` retains the plotted Z values and accompanying fitted expression, difference, and uncertainty columns. `source_data/heatmap_selection_audit.csv` records the selection and clipping rule, while `source_data/positional_example_full_membership.csv` retains full measured pathway membership. Each example panel combines the heatmap with pathway curves and selected fitted gene curves.

Pathway D(s) and S(s) use notebook 12's existing `local_pathway_curves` calculation, evaluated on the common measured-gene background for displayed pathways. D(s) summarizes local pathway enrichment of absolute gene Z ranks; S(s) summarizes relative rank direction against that same background. S(s) is not an absolute signed pathway effect, so read it alongside the signed gene-Z heatmap and fitted curves. Before adapting the background for display, notebook 14 recomputes the original saved D/S curves from the original fit and checks agreement with `pathway_local_curves.csv`; a mismatch stops the workflow. `source_data/common_background_pathway_DS.csv` holds the displayed curves.

The program overview uses the saved notebook 12 grouping without reclustering: it displays the 12 largest saved programs plus programs containing the main examples. `source_data/all_saved_programs_overview.csv` records all representatives, common member counts, test-family availability, and display flags; `source_data/all_saved_program_membership.csv` exports all saved memberships. A representative below the controlled family’s common-member size cutoff remains in the descriptive table and D/S source data, with unavailable benchmark status marked `?`. The overview does not assign new biological names to groups.

Native segment and smooth-segment signed-GSEA rows, spatial-rank ECDFs, and other method-discrepancy diagnostics are supplementary context. Native signed GSEA and unsigned spatial rank-AUC use different effects and null hypotheses; their disagreement does not establish that aggregation caused an individual pathway result. The cohort contains two healthy mouse specimens and two healthy human cortex sections from one donor. The section labelled “medulla” is also healthy cortex; findings remain exploratory and do not support population-level human inference.

For rendered figure checks, set `NATURE_FIGURE_QA_DIR` to the directory containing the existing figure-QA scripts before running the notebook or mirror. The plot saver then checks Matplotlib panel alignment and runs the PDF text and collision audits for each exported PDF. Without this variable, these optional QA scripts are not run.
