# Publication-readiness checklist

- [ ] Confirm data-sharing, consent, and annotation licenses before any public release.
- [ ] Choose and add an open-source license.
- [ ] Replace the private-data access instructions with an archival DOI or controlled-access URL.
- [ ] Re-run the active pipeline from a clean authorized environment and record software versions.
- [ ] Re-review manual cluster labels, PAGA gaps, and the physical-axis sensitivity results.
- [ ] Update `CITATION.cff` with authorship, version, DOI, and release date.
- [ ] Verify no restricted artifacts, local paths, notebook outputs, or credentials are tracked.
- [ ] Tag a release only after a fresh-clone CI pass and maintainer review.
