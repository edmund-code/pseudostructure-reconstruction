## What the paper actually does (from the full text)
- Model: a "spatial mixture-of-experts". A gating neural network G(x,y) (two hidden layers of 20, softmax) assigns each location to one of P domains with top-1 (hard) gating; each expert has its own domain-specific isodepth d_p(x,y) (one hidden layer of 20, then a single node) followed by a LINEAR expression function h_p,g(z) = alpha + beta z. So within a domain expression is linear in that domain's isodepth; between domains there is no shared coordinate (Methods 2.3-2.5). Theorem 1 shows a two-square example GASTON's single global isodepth cannot represent.
- Fitting: Gaussian loss on top GLM-PCs, then G x P Poisson regressions with library size offset (as in GASTON); 50,000 full-batch epochs, alternating updates of gate and experts, single initialisation; gate pre-trained on k-means (simulation) or CellCharter (real data) labels; P set to the true number or CellCharter's number.
- Calls: a gene has a gradient in domain p if |beta| exceeds a threshold set at "the fifth percentile" of all genes' |beta| in that domain (Methods 2.5). There is no test; the Discussion lists "a statistical testing framework for whether a domain contains gene expression gradients" as future work.
- Replicates: none; one sample at a time.
- Validation: checkerboard simulation (5 instances, 15 genes): ARI ~0.85 vs <0.70 for BANKSY, CellCharter, GraphST, GASTON; Kendall tau with true isodepth 0.33 vs GASTON 0.27; MERFISH mouse forebrain (ARI 0.717 vs <0.41; caudoputamen Cnr1 gradient); Visium breast cancer (hypoxia, TNF-alpha gradients; Hallmark enrichment via Enrichr, FDR < 1e-5).
- Plot types: domain maps with ARI; isodepth maps per domain; expression vs domain isodepth with fitted line; cell-type proportion vs isodepth; per-domain enrichment bars.
- Software: Python/PyTorch, github.com/raphael-group/GASTON-Mix.
- Limitations (authors): one gradient direction per domain; no test; radial geometries untested. For us: coordinates are learned from tissue x/y; domain-wise linear only; no jump parameter as such (domains are separate experts); no replicates.
