## What the paper actually does (from the full text)
- Model: per gene, a Gaussian process regression y ~ N(mu*1, sigma_s^2 * Sigma(l) + delta*I) on coordinates X (Methods eq. 1; Supp. Note 1 eq. 3). Sigma is a squared-exponential (SE) kernel with one characteristic length scale l. FSV = fraction of spatial variance, computed with Gower's correction as g/(g+delta) (Supp. Note 1 §1.2). Fitted by ML: closed-form mu and sigma_s^2 given delta, L-BFGS-B on delta, and l by grid search over 10 log-spaced values from half the smallest to twice the largest pairwise distance (Supp. Note 1 §1.4). FSV standard error by error propagation.
- Input data: counts are not modelled as counts. Expression is Anscombe-transformed for NB (log(y + 1/phi), phi fitted across genes) and log total count is regressed out before fitting; the GP assumes Gaussian residuals and independent observations (Methods "Expression count normalisation"; Supp. Note 1 §3). The total count itself is strongly spatially variable in every dataset (FSV 30-80%).
- Significance: LRT of the GP model against a no-spatial-covariance model, chi-square with 1 df; Storey q-values for FDR (Methods; Supp. Note 1 §1.3). Calibration: QQ plots on real data and on coordinate-shuffled data (Supp. Fig. 9), null simulations showing the test is conservative (Supp. Fig. 10E), MERFISH negative-control probes in line with FWER (Supp. Fig. 13D).
- Pattern classification: after significance, BIC model selection among SE ("general"), linear and periodic (cosine) kernels; BIC also gives approximate posterior model probabilities (Methods "Model selection"; Supp. Note 1 §1.3). The authors note that a long-period periodic kernel describes a sigmoidal rise or fall across the domain (Supp. Note 1 §1.3; Foxj1 example), and that "subtle noise can affect spatial function classification" (Supp. Fig. 15: Penk gets periodic posterior 0.12 while visually similar Nrgn gets 1).
- Automatic expression histology (AEH): a GP-prior mixture model over genes (K patterns, user-set length scale), fitted by variational Bayes (Supp. Note 1 §2).
- Replicates: none. Each analysis uses one section ("Replicate 11" olfactory bulb; "Layer 2" breast cancer; one SeqFISH region; one MERFISH replicate) (Methods "Data sets").
- Validation: mouse olfactory bulb ST (67 SV genes), breast cancer ST (115), SeqFISH hippocampus (32 of 249), MERFISH cell culture (91 of 140, 65%), and a 1-D frog developmental time course (21,009 of 22,256 genes variable, Supp. Fig. 14). Comparisons with HVG methods and with clustering + ANOVA (Supp. Figs. 5, 7, 8). Simulations of bell curves and of the GP model for power (Supp. Fig. 10).
- Plot types: FSV vs -log10 P scatter with FSV uncertainty (Fig. 2A, 2E); tissue maps of SV genes annotated with period or length scale and model posterior insets (Fig. 2C, 2G); AEH pattern maps (Fig. 2D, 2H); ANOVA vs SpatialDE P scatter (Supp. Figs. 5D, 7D); histogram of fitted length scales (Supp. Fig. 7E); time-course heatmap ordered by time of peak (Supp. Fig. 14C).
- Software: Python 3 package SpatialDE (PyPI), https://github.com/Teichlab/SpatialDE; a Stan implementation in the same repository (Code availability; Supp. Note 1 §7).
- Limitations (authors): Gaussian noise on transformed counts; future versions should model platform noise, tissue make-up and cell density (main text, last paragraphs); classification sensitive to noise (Supp. Fig. 15). Limitations for OUR design: one stationary length scale per gene cannot localise a transition, the length-scale grid has only 10 values, no exposure offset in the likelihood (log total count is regressed out instead), no replicates, and on a strongly structured 1-D axis nearly every gene is called (time-course example).

- c:57, "Two ideas carry over: the length scale (how far along S1->S3 a gene's variation extends, a continuous 'sharpness' index) and kernel-based classification (linear vs other)." - VERDICT: misses an important point. SpatialDE's length scale is one global, stationary smoothness parameter per gene, picked from a 10-point grid. It says how quickly the whole profile wiggles, not where or how sharply a single transition happens. A flat-then-step profile is not well described by a stationary SE kernel; SpatialDE's own notes say a long-period periodic kernel is what captures sigmoid-like trends. The kernel classification is also noise-sensitive (Supp. Fig. 15).
  Proposed replacement: "Two ideas carry over, both with limits. The fitted length scale is a global smoothness index per gene; it does not locate or time a single transition, so it cannot replace a sigmoid width. Kernel model selection by BIC (linear, periodic, general) gives model posterior weights per gene, the same idea as our model ladder; SpatialDE's authors show these labels can flip with small noise."

## Fit to our design (revised after reading the full text)
Low. It is a single-section, Gaussian-on-transformed-counts test with no offset and no replicates. Running it on our 1-D pseudospace would mostly reproduce our positional test (on the 1-D time course it called 94% of genes). The useful carry-over is the BIC-weighted kernel classification, which supports recommendation 1's "posterior class weights", not the length scale as a sharpness index.
