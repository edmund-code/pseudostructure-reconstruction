## What the paper actually does (from the full text)
- Model / statistic
  - Two modes ("spatial gradient screening"): spatial trajectory screening (STS; projection length along a
    straight user-drawn or programmatic trajectory, within a rectangle of set width) and spatial annotation
    screening (SAS; distance of each spot to the nearest vertex of an annotation polygon, radial). Annotations
    can be drawn on the image, or made automatically from clusters ("group annotations") or expression
    thresholds ("numeric annotations") (Methods, "Spatial annotations"; "Spatial trajectories").
  - Per gene: LOESS of normalized expression against distance; alpha set from resolution (default = spot
    centre-to-centre distance), distance screened and a completeness correction factor; predictions at bin
    centres (e.g. 30 estimates for 3 mm at 100 um); the vector is min-max scaled to 0-1 (Methods, "Inferring an
    expression gradient"). Input is Seurat-normalized (NormalizeData/SCTransform) expression, not a count model.
  - "Randomness" = total variation (sum of absolute differences between adjacent estimates) of the scaled
    gradient (eq. 4).
  - Pattern library: each gradient is compared with predefined model vectors by MAE and RMSE; default models of
    three kinds (descending = "association", ascending = "recovery", peaking = "layered"), shown in Supp. Fig.
    14d; user-defined models can be added (Methods, "Identification of biologically relevant pattern"). The
    output is a gene x model table of fits that the user filters (e.g. FDR < 0.05 and RMSE < 0.25 for the
    descending or ascending models; Methods, "Downstream analysis of sample #UKF313").
- Null / calibration / significance
  - Stated H0: no spatial relation to the reference feature (Methods, "Identification of non-random gradients").
  - Operational null: 10,000 gradients made by assigning random expression values to all data points in the
    screened area and running the same LOESS; outlying TVs removed by an IQR rule; P = fraction of random TVs <=
    observed TV; BH-adjusted "fdr" column, threshold 0.05 recommended (Methods, "Calculation of p-values").
  - So the null is spatially unstructured noise, not a permutation of the gene's own values and not randomized
    coordinates. Any smooth spatial structure, related to the reference or not, beats it.
  - Type I error < 5% was shown only against variables simulated as 100% noise, under shifted or rotated
    annotations and trajectories (Results, "Statistical challenges and benchmarking"; Supp. Figs 6, 12).
  - Optional estimate_r2: a per-setup simulation reporting how well TV tracks the noise ratio.
- Replicates / multiple samples handled? No. Screening is per sample. Six glioblastomas were "horizontally
  integrated" by row-binding their gradient estimates (getSasDf, 3 mm, 100 um) and plotting mean with 95% CI
  (Fig. 5d-j; Methods, "Horizontal integration"). No sample-level test.
- Validation: 61,200 simulations (6 patterns x 4 noise types x 0-100% noise in 2% steps); TV vs noise ratio C/R2
  0.77-0.92 for the realistic noise types; on 10,000 simulated genes the R2 of statistic vs noise was 0.75 for TV
  vs 0.59 (tradeSeq Wald) and 0.64 (PseudotimeDE, 1,000 genes) (Fig. 6a-c); runtime: 10,000 genes in minutes on a
  laptop. Real data: one glioblastoma with a tumour-transition-cortex trajectory (Figs 1-2), one mouse stab-wound
  brain (n = 1 mouse for Visium; Fig. 3), one glioblastoma with necrosis (Fig. 4), six glioblastomas for hypoxia
  vs T-cell abundance (Fig. 5).
- Key finding used by the review: area-specific DEGs from tumour and transition regions declined gradually across
  boundaries, while cortex DEGs dropped abruptly (Fig. 2d-h); the same with BayesSpace clusters (Supp. Fig. 2).
- Gene sets: SPATA2's "GSEA" is a hypergeometric over-representation test via hypeR on DEA results (Methods,
  "Gene set enrichment analysis"). In the paper, genes passing SAS were grouped by model class (descending vs
  ascending) and given to hypeR (e.g. HM_HYPOXIA, HM_OXIDATIVE_PHOSPHORYLATION). Gradients were also drawn for
  hypoxia signatures (Fig. 5d) and for deconvolved cell-type abundances (Fig. 5e-j); any numeric variable can be
  screened.
- Plot types: surface plots (spots on the image); line plots of gradients with 95% CI (Figs 2, 5); trajectory
  heatmaps of top DEGs (Fig. 2d-g); gradient ridge plots (Fig. 3c-f); pattern-model fits (Supp. Fig. 8d, not read).
- Software: R package SPATA2 (https://github.com/theMILOlab/SPATA2; tutorials https://themilolab.github.io/SPATA2/;
  reproducible version kueckelj/SPATA2 ref 0e3eb85).
- Limitations the authors state: needs careful placement of reference features (confounders, omitted
  structures); manual placement adds type II error; zero-inflated variables should be removed (rm_zero_infl);
  resolution cannot exceed what LOESS can fit (Discussion; Methods).
- Limitations for OUR design: single-sample, no replicate model; weak null (independent noise); normalized
  expression rather than counts with an offset; TV depends on the smoothing set by resolution and completeness;
  model fits are MAE/RMSE on 0-1 scaled curves with no model-selection criterion or uncertainty.

## Fit to our design (2-4 lines, revised after reading the full text)
Borrow the display (gradient line plots with CI, ridge plots) and the cheap 0-1 scaled shape-template matching as
a level-free pre-classification. Do not borrow its test: the total-variation null is independent noise, so along a
reconstructed PT axis almost every expressed gene would be "non-random". Our NB model ladder with specimen terms
and the relabeling control is the stronger test.
