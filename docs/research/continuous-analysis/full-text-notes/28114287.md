## What the paper actually does (from the full text)
- Census: converts per-cell TPM to relative transcript counts without spike-ins or UMIs. The mode of each cell's log-TPM density is taken as the TPM of a single captured mRNA; total captured mRNAs = number of genes between epsilon (0.1 TPM) and that mode divided by the fraction of the library they contribute, scaled by an assumed capture rate (0.25) to lysate counts (Online Methods "Census"). Limits: cannot correct non-linear amplification (log TPM ~ k log Y with k from ~0.5 to ~1).
- Differential tests built on Census counts:
  - BEAM (Branch Expression Analysis Modeling): two NB GLMs per gene with a natural spline (df 3, VGAM `sm.ns`) in pseudotime. Null: one curve; alternative: pseudotime x Branch interaction (a curve per branch). Likelihood-ratio test via VGAM `lrtest()`, "similar to Monocle's other differential expression tests". Progenitor cells before the branch point are split between the two branches by alternating pseudotime rank (odd/even) to keep observations independent (Online Methods "Testing for branch-dependent expression").
  - Branch time point: from the end of stretched pseudotime (t = 100), move back to the latest crossing of the two branch splines, then forward until the divergence exceeds a user threshold epsilon; that is the gene's branch time (Online Methods "Branch time point detection"). No uncertainty is attached.
  - Isoforms: Dirichlet-multinomial GLM in VGAM, LRT vs null; 74 genes with pseudotime-dependent splicing at FDR < 0.1.
  - Alleles: quasibinomial GLM, F-test; simulation-based prediction intervals.
- Null / calibration: BH-corrected LRT P values with cells as observations. Benchmark truth for DE = a permutation test on spike-in-derived levels (Fig. 2). With Census counts, DESeq2's empirical FDR fell from 61% to 22% and Monocle's from 53% to 11% at a 10% target (Results).
- Replicates: none; cells are independent observations.
- Validation: eight spike-in datasets (total counts, fold changes, ROC curves), downsampling and simulation (Supplementary Figs 3-4); biological re-analyses (lung AT1/AT2, 1,219 BEAM genes; dendritic cells with Ifnar1/Stat1 knockouts, 870 genes; myoblast splicing; preimplantation allelic balance).
- Plots: per-branch spline fits with null-model dashed curve (Fig. 3c); kinetic clusters of branch-dependent genes (Fig. 4c, the branched heatmap); branch time point boxplots for regulators vs targets (Fig. 4d,e); PSI vs pseudotime with loess (Fig. 5).
- Software: R, Monocle 2 (Bioconductor; GitHub cole-trapnell-lab/monocle-release).
- Limitations for us: our data are probe counts aggregated over segmented units, not full-length TPM, so Census itself is irrelevant; BEAM is a cell-level LRT with no sample effect.

## Review check
- a-gene-dynamics.md:31 (row 11) - "Qiu et al. 2017 (Census/BEAM) ... BEAM is a GLM for genes that depend on the branch." - VERDICT: correct (NB GLM, spline x branch interaction, LRT).

- a-gene-dynamics.md:31 - "Little that we lack. BEAM assumes branching." - VERDICT: misses a point. BEAM's spline-x-group LRT is the same construction as a condition-x-position test (AKI vs control) with cells as observations, and its per-gene branch time point (last crossing of the two group splines, then a divergence threshold) is a simple, deterministic divergence-position estimate. Suggested addition: "BEAM's branch-time-point rule (last crossing of the two fitted curves, then a divergence threshold) is a cheap point estimate of where two conditions part, with no uncertainty; with our specimen fits it could be computed per specimen pair."

Caveat from the BGP paper (PMID 29843817, Figs 3 and 6): BEAM's branch-time estimates are biased toward the global branching time, and its last-crossing rule picks the wrong crossing for transient genes. So the heuristic is weak for genes with mid-axis bumps.

## Fit to our design (revised after reading the full text)
Census is irrelevant to probe counts. BEAM is a cell-level NB spline-by-group LRT, which we would not use for inference (cells as replicates over-call). Its branch-time-point heuristic could serve as a crude descriptive divergence position for IR vs control on specimen-level curves, but it fails for transient (mid-PT) genes; a posterior over the divergence point (DEtime) is better.
