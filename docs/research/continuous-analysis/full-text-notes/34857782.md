## What the paper actually does (from the full text)
- Data: original Spatial Transcriptomics arrays (100 um spots, 150-200 um spacing) on 8 sections from 3 samples (caudate and right lobes) of female C57BL/6 mice; 4,863 spots, 19,017 genes; 10-60 cells per spot (mean 32) by immunofluorescence counts (Results; Methods "Collection").
- Clustering: SCTransform, MultiCCA integration across sections (github.com/almaan/ST-mLiver), Louvain clustering into 6 clusters; cluster 1 periportal, cluster 2 pericentral (matched to histological vein annotations), cluster 5 mesenchymal, proposed Glisson's capsule (Figs. 1-2, 4). Wilcoxon DGE with Bonferroni; Seurat module scores; stereoscope deconvolution with bootstrap CIs on co-localisation correlations.
- Coordinate: physical distance from each spot centre to the nearest pixel of an annotated vein mask (central or portal), within 400 um (Methods "Features as a function of distance").
- Univariate model: "expression by distance" plots, loess-smoothed with SE ribbons, spots from all sections pooled (Fig. 3b).
- Bivariate model: OLS of expression on distance to the nearest central vein and to the nearest portal vein; nested reduced models (central only, portal only, intercept only) compared by likelihood-ratio tests (Methods "Bivariate expression by distance analysis", "Model comparison"; Fig. 3c). For central and portal markers both distances mattered (full model beat both univariate models).
- Steep vs gradual: "certain genes (e.g., Glul, Slc1a2, and Oat) show a steep decrease in expression as the distance from a central vein increases, while others (e.g., Cyp2e1 and Cyp2a5) display a more gradual decline", interpreted as "compartment type" vs "gradient type" genes (Results; Discussion). Judged by eye from loess curves.
- Vein classifier: L2-penalised logistic regression on distance-weighted neighbourhood expression profiles of 10 marker genes (5 central, 5 portal), cross-validated by leaving out sections and samples; assigns 72 ambiguous veins, partly checked by GS/SOX9 staining (Fig. 3d-e).
- Null / replicate unit: spots (and sections) pooled; LRTs and DGE treat spots as independent; cluster-interaction analysis uses 100 label permutations; the classifier is the only analysis validated across sections and samples.
- Plot types: cluster maps on H&E; UMAP; marker heatmaps; expression-by-distance loess curves with SE ribbons (central vs portal); bivariate expression-by-distance heatmaps; vein-class probability maps; module-score maps.
- Software: R (Seurat, STUtility), Python module hepaquery for distance and classification analyses, stereoscope; code https://github.com/almaan/ST-mLiver and Zenodo 5595907; data GEO GSE165141.
- Limitations (authors): small sample size; lobule geometry not resolvable from vein markers; scRNA-seq integration limited. For OUR design: tissue x/y coordinate (excluded for our reconstruction); spot-level pooled tests.
