## What the paper actually does (from the full text)
- Model / statistic: a benchmark of 14 DE methods for comparing a cell type between conditions: 7 single-cell tests (t, Wilcoxon, logistic regression, NB and Poisson GLM, LRT, MAST via Seurat FindMarkers), 6 pseudobulk tests (DESeq2 Wald/LRT, edgeR LRT/QLF, limma-trend/voom on counts summed per biological replicate), and a linear mixed model; later 8 Poisson/NB GLMMs.
- Null / calibration: (1) concordance (AUCC, k = 500 genes; GO-term AUCC with fgsea, k = 100) between scRNA-seq DE and matched bulk RNA-seq DE in 18 "ground truth" data sets (plus proteomics); (2) null comparisons: Splatter simulations with replicate heterogeneity but no group effect; random splits of control groups in 14 data sets with >= 6 controls; random splits of control mice in a spatial transcriptomics ALS spinal cord data set (DE within each region).
- Replicates: the central point. Pseudobulk methods were the top six; applying the same tools to single cells, or to "pseudo-replicates" (cells shuffled across replicates before summing), removed their advantage and introduced a bias toward highly expressed genes (Fig. 3). Shuffling lowers between-replicate variance for 98.2% of genes in one data set and in all 46 data sets examined (Fig. 3e-f).
- Validation: single-cell methods called hundreds of DE genes with no true difference (simulations; real control splits), with DE genes enriched for hundreds of GO terms (Supp. Fig. 6c); in the spatial data, methods ignoring replicates found thousands of DE genes per region while pseudobulk did not (Fig. 4f). More replicates reduced false discoveries; more cells made them worse (Supp. Fig. 4c-d). Human data sets had more between-replicate variability than mouse (Fig. 4g). In vivo: snRNA-seq of lumbar spinal cord after SCI (19,237 nuclei), RNAscope confirmed 5/6 edgeR-LRT-only genes vs 3/13 Wilcoxon-only genes (Fig. 5). GLMMs matched pseudobulk only at >= 500 cells and needed about 13.5 h per cell type; the LMM performed poorly (Results, "DE analysis with mixed models").
- Plots: AUCC heatmaps/bars per method and data set; GO-term rank example; expression-tercile AUCC; ERCC spike-in scatter of mean vs -log10 P; variance change (biological vs pseudo-replicates); number of false DE genes vs heterogeneity; volcano plots of null comparisons; RNAscope validation bars.
- Software: R package Libra (https://github.com/neurorestore/Libra); analysis code https://github.com/neurorestore/DE-analysis; modified Seurat.
- Limitations for us: tests are two-group, cell type between conditions; no trajectory or along-axis tests; default simulations used 3 replicates per condition.

## Fit to our design (2-4 lines, revised after reading the full text)
The strongest general evidence that units within a specimen are not replicates, extended explicitly to spatial spots and to downstream GO enrichment; it supports our specimen-level calibration. It says nothing about curve or position tests, and its pseudobulk remedy assumes several replicates per group (we have 2 vs 2), where any test has very few degrees of freedom.
