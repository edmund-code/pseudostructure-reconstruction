## What the paper actually does (from the full text)
- Model / statistic: Seurat preprocessing; user selects clusters; HVGs of these clusters build a reference trajectory with Monocle DDRTree (direction user-reversible). For each pathway (genes with missing expression removed; pathways < 20 genes dropped), DDRTree is re-run on that pathway's expressed genes alone to give a pathway pseudotime; the score is the absolute Pearson correlation between pathway and reference pseudotimes. DDRTree is also run on random gene lists of the same size (1,000; Fig. 1 legend) to set a 5% FDR per pathway size; pathways are called if below 5% FDR "and which have significant correlation in terms of absolute gene expression (>0.6)" (Methods, "Pathway inference"; wording ambiguous, read as |r| > 0.6).
- Timing: switchde switch points of the pathway's significant genes; their distributions per pathway give a "temporal alignment" (Figs 3F, 4F). SOMs (kohonen) to inspect monotone vs complex pathways.
- Driver genes: switchde switch-like genes; Pearson r of expression with pseudotime; and "DDRTree influence" = drop in the pathway's correlation when one gene is removed (leave-one-out), which found non-switch-like, non-monotone genes (Supp. Figs S6-S7).
- Null / calibration: random gene lists of matching size, cells as units. No replicate (donor/sample) handling.
- Validation: Splatter simulation (500 cells, 5,000 genes; 1,000 random lists vs 100 lists drawn from the 527 HVGs that built the reference): mean list expression did not separate HVG lists from random lists, pathway-pseudotime correlation did (Fig. 2A-C); significant HVG lists contained balanced rising and falling genes (Fig. 2D-E); correlation grows with list size and random-list noise also grows with size (Fig. 2F, I); dropout degrades correlation sharply (Fig. 2H); cell subsampling barely matters (Fig. 2G). Real data, qualitative: 69 CD8+ T cells from one healthy donor (scSTATseq); CD8 T cells from a protocol benchmark (GSE133535; 4 of the highlighted pathways recurred in >= 3 of 4 data sets); HCC TILs (51/1,114 pathways significant); HCC after checkpoint blockade (52/965); T2D islets. Fig. 3D notes that some large pathways had high correlation but were indistinguishable from random sets of matching size. Swapping DDRTree for Slingshot, Embeddr, Component1, MATCHER or Angle changed results; Component1 and MATCHER had the most hits and the highest random-list background (Supp. Fig. S12).
- Plots: UMAP/trajectory plots; volcano of pathway correlation vs FDR (Figs 3D, 4D); pathway dot plots; switch-point "temporal ordering" distributions per pathway (Figs 3F, 4F); scaled gene expression along pseudotime (Figs 3G-J, 4G-J); simulation scatter/box plots (Fig. 2).
- Software: R/Shiny GUI, https://github.com/qingshanni/TIPS, and a web server (http://118.24.236.198:3838/TIPS/).
- Limitations (authors): switchde assumes single abrupt switches; dropout and pathway size affect accuracy; trajectory algorithm choice matters. Limitations for us: in an axis-dominated data set (as PT is), random gene lists also rebuild the axis, so the background is high and the score separates little; the reference uses the same genes; cells are the replicates.

## Fit to our design (2-4 lines, revised after reading the full text)
Conceptually the closest published "does this pathway's gene set recover the axis" score, and its leave-one-gene-out driver ranking is a useful idea. As implemented it is uncalibrated for our design (cells as replicates, circular reference, algorithm-dependent), and on PT nearly any gene set would recover the axis, so its main lesson is the need for a matched random-set baseline and held-out genes.
