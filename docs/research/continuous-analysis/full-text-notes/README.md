# Full-text reading notes (2026-10-14)

One note per paper cited in the continuous-analysis review. Each paper was read end to end:
- methods;
- results;
- figure legends;
- the supplement where it was open.

Each note, named by PMID or by DOI/URL with punctuation replaced, records:
- **Read status:** full text, preprint, partial, or abstract only with what was tried.
- **What the paper actually does:** model, null, replicate handling, validation, plots and software, with the section
  or figure for each fact.
- **Review check:** every place the review cites the paper, with a verdict (correct, wrong, unsupported, or misses an
  important point) and replacement text.
- **Fit to our design**, revised after the full-text read.

Paths such as `ws_ft/dl/` or `ws_ft/dl_extra/` inside the notes refer to a temporary download cache. It is not kept:
downloaded papers are not stored in the repository. The synthesis is `../../continuous-analysis-literature.md`.
