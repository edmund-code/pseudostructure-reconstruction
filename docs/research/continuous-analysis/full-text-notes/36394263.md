## What the paper actually does (from the full text)
- Model / statistic:
  - Trees/curves: SimplePPT (soft assignment R), ElPiGraph (tree, curve or circle; hard assignment), or SimplePPT on CellRank absorption probabilities + pseudotime (main text; supplement). Pseudotime = distance on the graph from a root, cell projected between its two nearest principal points; soft assignment gives several "mappings" to carry position uncertainty (not available with ElPiGraph's hard assignment unless converted).
  - test_association (supplement "Testing for features associated with the tree"; docs): per branch, a GAM (mgcv, Gaussian errors, identity link, on normalised expression; spline_df 5) of expression on pseudotime vs an intercept-only model by F-test; BH FDR. The docs add an amplitude filter A = max - min of the GAM prediction (A_cut default 1) and a stability filter across mappings (st_cut 0.8); fdr_cut default 1e-4.
  - fit / cluster: same GAM smooths; clustering = PCA of fitted features, kNN graph, Leiden (not k-means).
  - Covariate test (supplement eq. 7-8; docs test_covariate): within one path, first test_association per condition; then "amplitude" test = p-value extracted from the s(pseudotime):Covariate interaction term of g ~ s(pt) + s(pt):Covariate + Covariate; "trend" test = ANOVA of that model vs g ~ s(pt) + Covariate (docs: "inspired from a preprint [Ji22]"); a nested option tests shared trend then specific trend. Both tests target the interaction smooth; neither tests a constant level shift (the Covariate main effect).
  - Linearity deviation (supplement eq. 9; docs): for bridge cells B between progenitors A and progeny C (default pseudotime percentiles 20/80), each cell's profile is regressed (lm, no intercept, across genes) on the mean profiles of A and C; per gene, mean residual over B cells normalised by the gene's SD ranks genes specific to the transition. Purpose: check whether a bridge is a doublet artefact and find transient genes. It is a ranking; no p-value is given.
  - Bifurcation tools: test_fork (GAM with branch interaction), branch_specific, activation timing (10 pseudotime bins or linear model), local gene-gene correlation, repulsion score, module inclusion timing with local permutations.
- Null / calibration: F-test / ANOVA / Wald-type p-values with BH; cells are observations. No sample-level null.
- Replicates: not modelled. The covariate example integrates "two experiments" (Fig. S3) with cells as units.
- Validation: runtime and overlap benchmarks against STREAM (3,217 cells) and Monocle3 (6,188 cells), tree inference on 150,000 cells (Fig. S1); illustrative examples (forebrain bridge Fig. S2, EMT covariate Fig. S3, Palantir bone marrow Fig. S5). No calibration or power study.
- Plots: trend heatmaps, single trends, matrix plot over pseudotime bins per segment, module means, correlation/repulsion plots (Fig. S5).
- Software: Python scFates (PyPI, GitHub LouisFaure/scFates), BSD-3.
- Limitations stated: SimplePPT may give less consistent trees; Moran's I faster but no amplitude. For OUR design: Gaussian GAM on normalised expression (no NB, no exposure offset), cells as replicates, p-values not calibrated across specimens.

## Fit to our design (2-4 lines, revised after reading the full text)
Already our curve tool (ElPiGraph curve). Its gene tests are Gaussian GAMs on normalised expression with cells as observations, so they cannot replace our specimen-level NB fits. The linearity-deviation idea (is mid-PT expression a mixture of S1 and S3 means?) is a useful descriptive screen for transient genes and for the continuous-vs-discrete question, if run per specimen on aggregated units. Its condition tests do not give a level-vs-shape split.
