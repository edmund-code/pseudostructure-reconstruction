## What the paper actually does (from the full text)
- Model: per gene, polynomial regression in time with S-1 dummy variables for series (groups) and their interactions with the time terms (Methods 2.1; the original Conesa 2006 design). Next maSigPro swaps `lm()` for `glm()` in both steps; `counts = TRUE` uses an NB family. The NB dispersion theta is a single user-set value: "When no estimation of theta is possible, we recommend to use the default value, theta = 10"; "results do not change much by using different values of theta" (Methods 2.1). Other exponential families are allowed via `family`.
- Two steps: (1) `p.vector()`: deviance (LR) test of the full polynomial model vs a model without covariates (chi-square), FDR-controlled, selects non-flat genes; (2) `T.fit()`: stepwise regression keeps only significant coefficients per gene, then a goodness-of-fit filter R2 (percentage of deviance explained) removes poorly fitted genes. Recommended R2 cutoff 0.7; 0.5 with more data (Results 3.1, Discussion).
- Normalisation: none inside maSigPro; data must be normalised beforehand (TMM used). No offset is described.
- Null / calibration: chi-square deviance tests with FDR; replicates enter as repeated observations at each time point (no replicate random effect). In simulation (NB, theta = 10, 6 time points, 20,000 genes, 5% DE; scenarios linear up, up/down, early spike), with >= 2 replicates maSigPro-GLM kept FDR < 5% (at R2 >= 0.7) while edgeR gave 11-20% false calls; one replicate was "clearly insufficient" (Table 2, Discussion). FDR control depends on the R2 filter (Fig. 1).
- Real data: Arabidopsis response to powdery mildew, 4 time points, 2 series, 3 replicates; 2,158 maSigPro vs 2,870 edgeR DEGs, 1,629 shared; edgeR-only genes mostly failed the R2 filter (outliers, high variance; Fig. 2).
- Plots in the paper: FDR/FNR vs R2 (Fig. 1); example gene profiles per selection set (Fig. 2). Clustering and visualisation functions are said to be unchanged from earlier maSigPro but are not shown here.
- Software: R/Bioconductor `maSigPro`, LGPL.
- Limitations stated: needs replication; LM on normalised counts performs poorly unless ~5 replicates. Limitations for us: fixed common theta; stepwise selection makes per-coefficient P values post-selection; low-degree polynomials cannot follow sharp edges; units-as-replicates would repeat the cells-as-replicates problem; with 2 specimens per group, specimen-level replication is at the edge of what the simulation tested (2 replicates did control FDR there, but on clean NB simulations).

## Fit to our design (revised after reading the full text)
Readable group x position terms, but a fixed-dispersion, fixed-effect polynomial GLM with stepwise selection. For us it would only be a descriptive decomposition (offset, slope, curvature differences) on specimen-level pseudobulk bins; our per-gene NB dispersion, exposure offset and specimen relabeling are stricter than what it offers.
