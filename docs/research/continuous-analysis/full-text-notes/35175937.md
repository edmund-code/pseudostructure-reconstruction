## What the paper actually does (from the full text)
- Model / statistic (Methods):
  - Input: raw counts (genes x samples) plus a user-defined BASELINE time (e.g. 0 h). Optional limma batch correction/normalisation; scRNA-seq converted to per-cell-type pseudobulk per sample (cell types <1000 cells dropped; edgeR filterByExpr; RLE).
  - (a) Baseline: NB with DESeq2 dispersion; 90% interval of baseline counts. (b) Non-baseline time points: smoothing-spline ANOVA with NB family (penalised likelihood, Eq. 5-9). (c) Each non-baseline fitted mean tested against the baseline NB distribution (one-sided, Eq. 10). (d) Gene-wise dynamic P = Fisher combination over time points (Eq. 11).
  - Trajectory pattern: connect significant time points (P < 0.05), then break points = local maxima (type I) or minima (type II) of fitted means (Eq. 12); master pattern and sub-pattern per gene, e.g. "0D-2D up, 2D-14D down".
  - TimeHeatmap (Methods; Fig. 2D legend): windows are consecutive time-point intervals [t_j-1, t_j]; in each window, up- and down-regulated DDEGs separately go into Fisher's exact GO enrichment; the top pathways per window (default 10) are kept; each cell shows the average log2FC of that pathway's DDEGs relative to the previous window; extra columns %GO and nDDEG. Sum of the row = "GO_mean_logFC", used to rank pathways (2-sided bar plot).
  - Between-group test (Methods "Permutation testing"): LOESS curves per group, time binned into 100 intervals, area ratio between curves per interval, group labels shuffled on the longitudinal profiles 1,000 times, empirical P per interval. Used to say when severe and mild/moderate groups separate (Supp Fig. 8).
- Null / calibration: baseline NB interval per gene; Fisher combination of per-time-point P values (which are not independent); Holm-Bonferroni for enrichment. Simulation: 10,000 genes, 3 replicates per time point, 3-11 time points; AUC 0.88-0.92 vs DESeq2, DESeq2Spline, ImpulseDE2 (Fig. 1B-C). Real-data comparison only by overlap.
- Replicates: replicate samples per time point enter the spline fit as observations. No subject/patient random effect; repeated measures from the same patient are not modelled. Groups (severity) are analysed separately, then compared.
- Validation: simulations; four public datasets (non-human primate blood, PBMC scRNA-seq mild, whole-blood bulk by severity, PBMC scRNA-seq moderate/severe, vaccination PBMC scRNA-seq of 56 people).
- Plots: observed counts + fitted spline per gene; trajectories per pattern group; hierarchical pie chart of pattern composition; TimeHeatmap; 2-sided bar plot of accumulated log2FC; LOESS pathway curves by group (Fig. 4D-G, 5B).
- Software: R package TrendCatcher, GitHub jaleesr/TrendCatcher.
- Limitations (authors): blood samples only; none on the method. For OUR design: every test is anchored to a baseline time point, which a PT axis lacks; windows are the gaps between sampled time points; the between-group permutation shuffles labels without specimen structure and without correction across the 100 intervals.

## Fit to our design (2-4 lines, revised after reading the full text)
Borrow only the TimeHeatmap layout (pathways x PT windows, coloured by member change), computed from our specimen-level curves. Its gene test (each time point vs a baseline interval, Fisher-combined) has no analogue on an anatomical axis without a baseline, and its replicate handling is pooling, not a specimen-level model.
