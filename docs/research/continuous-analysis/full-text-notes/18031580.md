## What the paper actually does (from the full text)
- Model / statistic: module eigengene E = first right-singular vector of the module's expression matrix after "each gene expression profile ... has been standardized to mean 0 and variance 1"; its sign is fixed "by constraining it to have a positive correlation with the average gene expression across module genes"; it typically explains more than 50% of module variance (Methods, "Module eigengenes"). Eigengene network: signed adjacency (1 + cor(E_I, E_J))/2; meta-modules by average-linkage clustering of eigengenes. Consensus modules: clustering on 1 - min over data sets of TOM (or a quantile); a "generalized consensus" built from per-data-set modules is offered as a robust alternative. Preservation network: 1 - |cor_1(E_I,E_J) - cor_2(E_I,E_J)| / 2, with per-eigengene connectivity and overall density D(Preserv) as descriptive preservation measures.
- Null / significance: permutation test of the number of genes assigned to consensus modules (permuting gene labels in one data set; p <= 0.001 in all applications, but dependent on the branch-cut height, Fig 4); eigengene-trait correlations with p-values; t-tests of eigengenes across brain regions. Preservation measures are descriptive; a permutation test is suggested.
- Replicates: arrays are the samples; each data set needs enough samples to estimate correlations; no specimen-level model.
- Validation: three applications: human vs chimpanzee brain (7 consensus modules; eigengene-network preservation D = 0.93; three meta-modules preserved), four female mouse tissues (11 consensus modules; D 0.85-0.93), female vs male mouse liver (D = 0.94; eigengene-trait correlations); simulation of consensus detection (sensitivity, specificity, fidelity versus noise and cut height, Table 1).
- Plot types: gene dendrogram with consensus module colour band; eigengene dendrograms (meta-modules); eigengene adjacency heatmaps per data set; preservation barplots and preservation heatmaps; eigengene differential expression across regions (Fig 2H) and module-trait correlation heatmaps (Fig 5H-I); member-gene lines with the eigengene across samples (Fig 1C-E).
- Software: R code and tutorials (WGCNA framework).
- Limitations stated: minimum-based consensus is biased when networks differ for non-biological reasons ("different microarray platforms, gene expression normalization methods, or different sample sizes"); scale the TOMs or use the generalized consensus. Consensus modules by definition miss data-set-specific modules. Cut parameters affect results; robustness analysis advised.
- Limitations for OUR design: species-specific probe panels and unequal unit counts per specimen are exactly the non-biological differences the authors warn bias the minimum-based consensus; consensus across mouse and human specimens needs scaled TOMs or the generalized consensus.

## Fit to our design (2-4 lines, revised after reading the full text)
Per-specimen eigengene curves along PT are a sound, sign-fixed module summary, and the preservation measures (how eigengene-eigengene correlations hold up between mouse and human, or control and AKI) give a compact "is the program architecture conserved" figure. Build consensus with scaled TOMs or per-specimen modules because panels and unit counts differ, and treat all of it as descriptive.
