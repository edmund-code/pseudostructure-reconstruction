## What the paper actually does (from the full text)
- Problem: estimate a latent variable L (clusters or pseudotime) from counts X, then test each gene for association with L-hat(X). Using the same X for both ("double dipping") gives anti-conservative p-values (Fig. 1: 5 Poisson(5) genes, k-means k=2, all Wald p small; Sec. 3.2, Fig. 2a).
- Model: X_ij ~ Poisson(gamma_i Lambda_ij), log Lambda_ij = beta0j + beta1j' L_i, size factors gamma_i as GLM offsets (eq. 2.1, 2.4). Target parameter = KL projection of the GLM on the estimated L (eq. 2.2).
- Existing fixes reviewed (Sec. 3): cell splitting fails because test cells' coordinates must be computed from test data (projection), so p-values stay anti-conservative (Sec. 3.3, Fig. 2a). Gene splitting gives valid (uniform) p-values but cannot give every gene a p-value against the SAME estimated L (Sec. 3.4). Selective inference needs normality and a bespoke conditioning event (Sec. 3.5; App. C shows Gao 2022 selective test fails on log Poisson data). Jackstraw is miscalibrated per gene when genes differ in mean (Sec. 3.6). PseudotimeDE's permutation null is anti-conservative (Sec. 3.7).
- Count splitting (Algorithm 1, Sec. 4.1): X_train ~ Binomial(X, eps), X_test = X - X_train. Estimate L on X_train; regress X_test on L-hat(X_train) with offsets. Under Poisson the two halves are independent (Prop. 1), so any downstream test inherits its usual guarantees (Remark 4.1: not tied to GLM or Wald).
- Not Poisson (Sec. 4.2): independence holds IF AND ONLY IF the counts are Poisson. For NB with mean Lambda and variance Lambda + Lambda^2/b, Cor(X_train, X_test) grows with Lambda/b (Prop. 2, eq. 4.15). Fig. 2b: near-uniform p-values for Lambda/b = 0.1-1; at Lambda/b = 10 performance "approaches that of the double dipping method".
- eps trade-off (Sec. 4.3, Props 3-4): Cor(X, X_train) = sqrt(eps); test-half variance inflated by 1/(1-eps). Recommend eps = 0.5.
- Null/calibration: Wald GLM p-values on X_test; QQ plots against Unif(0,1). Replicate unit = cell; no sample-level replicates.
- Validation: simulations (n = 2700 cells, p = 2000 genes; trajectory = PC1, clusters = k-means; Figs 3a-c, Table 1 CI coverage about 0.95). Real data: Elorbany 2022 iPSC-to-cardiomyocyte scRNA-seq (10,000 cells, 2,500 HVGs, Monocle3 pseudotime). All days: count splitting and double dipping find the same genes; Day-0-only cells (no true trajectory): count splitting is uniform, double dipping is not (Fig. 4). Estimated Lambda/b mostly < 1 in that dataset (App. F, Fig. 7).
- Plot types: uniform QQ plots of null p-values (Figs 2-6); count-split vs double-dipped p-value scatter (Fig. 4 left).
- Software: R package countsplit (anna-neufeld.github.io/countsplit); code github.com/anna-neufeld/countsplit_paper.
- Limitations stated: Poisson assumption; fails for strongly overdispersed counts; works worse on shallow data (low intercept genes, small eps; Sec. 5.3-5.4); size factors assumed known; future work on overdispersed splitting (Sec. 7). A follow-up preprint "Negative binomial count splitting for single-cell RNA sequencing data" (arXiv 2307.12985, same authors) exists - title checked only, NOT read.
- Limitations for OUR design: our units are aggregated tubule cross-sections with large counts per gene, and we model them as NB. Lambda/b is then likely >> 1 for many genes, the regime where Poisson count splitting is no better than double dipping (Fig. 2b). Gene splitting (our sha256 gene folds) is valid per Sec. 3.4 and is the method that fits us; its only drawback (not all genes against one axis) is handled by our fold rotation. Also, Sec. 3.3 implies that projecting held-out specimens/units onto a curve re-uses their counts: cross-specimen transfer does not by itself remove circularity.

## Fit to our design (2-4 lines, revised after reading the full text)
The paper supports our gene-fold protection directly: gene splitting is valid (Sec. 3.4). Count splitting, its headline method, assumes Poisson; our aggregated units are high-count NB data, the regime where it degrades toward double dipping (Prop. 2, Fig. 2b). So recommend gene folds, not count splitting, and note that cross-specimen projection is cell splitting, which the paper shows is still circular.
