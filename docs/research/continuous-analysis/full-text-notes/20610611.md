## What the paper actually does (from the full text)
- Model / statistic: limma linear model per probe with design X, optional sample weight/correlation matrix W (array weights or correlated samples, Smyth et al. 2005), empirical Bayes moderated t for one contrast beta_g = c'alpha_g, converted to z. Set statistics (Section 3.3): mean, msq (mean of squared z), mean50 (mean of the top half), floormean (z floored at 0, or |z| floored at 0.67 for mixed). Optional gene weights (e.g. +/-1 or log-fold changes from another experiment).
- Null: SELF-CONTAINED, H0: beta_g = 0 for all genes in the set. Alternatives: Up (at least one beta_g > 0), Down, Mixed (Section 3.1). Discussion: "our methodology is for self-contained tests".
- P-values: rotation (Langsrud 2005): project out nuisance coefficients, randomly rotate the d+1 residual vector, recompute T; p = (b+1)/(B+1), exact; preserves inter-gene correlation; works for any linear-model contrast and small samples. "Active proportion": fraction of genes with z beyond a threshold motivated by AIC.
- Replicates: RNA samples; residual df d = n - p drive the rotation; correlated samples (blocks) handled through W, with the intra-block correlation estimated by the Smyth et al. 2005 method (0.08 in the example).
- Validation: simulations with 3 or 5 replicates per group (plus a 20-sample third group, or 2x2 factorial), sets of 40 or 1000 genes, 10 scenarios (up, mixed, partial activity, correlation 0 or 0.1); size held (also under exponential data); mean best when all genes change, msq best for a minority, mean50/floormean intermediate; compared with GSEAlm (which fails to hold size with few permutations). Real data: a MOUSE mammary stem-cell signature (2,754 human orthologs, gene weights = mouse log-fold changes) tested in HUMAN sorted cells (12 arrays, 3 patients), showing conserved direction (Table 3).
- Plot types: none beyond tables.
- Software: limma function roast (Bioconductor).
- Limitations stated: rotation assumes multivariate normality (shown robust); no statistic is best in all cases; with non-mean statistics a set can be significant both up and down. Extension to several contrasts at once via F-statistics is "easy" but not done here.
- Not in this paper: fry. (fry is in later limma documentation.)
- Limitations for OUR design: (1) Self-contained H0 (no member changes) is false for almost every PT pathway along position, so a positional ROAST would call nearly everything (the review says so itself in row 9). (2) The replicate unit is whatever the columns of the design are; on specimen-by-bin pseudobulk the residual df come from bins within specimens, so bins, not specimens, become the unit unless specimen is a block whose correlation is estimated, which is weak with 2-4 specimens.

- b:21 - Repl. "Yes (sample-level linear model; duplicateCorrelation for blocks)" - VERDICT: correct (W matrix; intra-block correlation by Smyth et al. 2005 in the mammary example).
- b:21 - Fit (i): "for directional one-df questions (linear PT slope, S3-end minus S1-end fitted value, species-by-position slope), run fry/ROAST on specimen-by-bin pseudobulk, which gives a self-contained test with specimens as the unit" - VERDICT: wrong on two counts. (a) On specimen-by-bin pseudobulk with a position covariate, the residual df come from bins, so the bins are the replicate unit, not the specimens; making specimens the unit needs a specimen block with an estimated intra-specimen correlation, which 2-4 specimens cannot estimate well. (b) The self-contained null (no member has a non-zero slope) is false for almost every PT set, which the review itself states in row 9 point (3), so a positional ROAST would call nearly every pathway. Proposed replacement: "ROAST/fry are self-contained, so a positional slope test would call almost every PT set. Use them only for contrasts where 'no member changes' is a plausible null, such as AKI-versus-control or human-versus-mouse shape differences, with one value per specimen (for example, each specimen's fitted slope) so that specimens are the unit; with 2 versus 2 the residual df are tiny, so report it as descriptive. ROAST's gene weights also allow a direct conservation test: weight members by the mouse positional slope and ask whether human members move the same way, as the paper did for a mouse signature in human cells."

## Fit to our design (2-4 lines, revised after reading the full text)
Not a pathway selector for positional questions (self-contained). Its most useful feature for us is the weighted directional test used in the paper's own mouse-to-human example: gene weights from mouse positional slopes, tested on human (or AKI) per-specimen statistics, asks "is the mouse positional program conserved in direction?" with correlation preserved. Replication must come from specimen-level values, so with our cohort it is descriptive.
