## What the paper actually does (from the full text)
- Model / statistic: co-expression similarity |cor| (or signed (1+cor)/2; robust options biweight midcorrelation, Spearman) raised to a soft-threshold power beta chosen by the approximate scale-free topology criterion (pickSoftThreshold); topological overlap (TOM) dissimilarity; average-linkage hierarchical clustering; modules = branches cut by constant height or Dynamic Tree Cut. Module eigengene = first principal component of the module ("a weighted average expression profile", moduleEigengenes); hub genes; fuzzy module membership kME = cor(gene, eigengene). Consensus modules across several networks: consensus similarity = minimum (or a quantile) of the input similarities (blockwiseConsensusModules). Block-wise detection for large gene numbers.
- Null / significance: none built in beyond correlation-test or regression p-values for eigengene-trait and membership relationships; module significance = mean gene significance. Described as exploratory and hypothesis generating, to be validated in independent data.
- Replicates: samples (arrays) are the observations over which correlations are computed; no replicate or specimen-level model.
- Validation: one illustration, female mouse liver (3,600 most connected genes, 18 modules; brown module eigengene r = 0.59 with body weight; DAVID enrichment of modules). Simulation functions are provided, not a benchmark.
- Plot types: scale-free fit plot (Fig 2A), MDS plot (2B), TOM heatmap with dendrograms and module colour bars (2C, 4B), gene dendrogram with module colour row (4A), barplot of module significance (3A), gene significance versus module membership scatter (3B, 4E), eigengene dendrogram and eigengene-network adjacency heatmap including the trait (3C-D, 4C-D), hub-gene network (4F).
- Software: R package WGCNA (GPL 3); tutorials online.
- Limitations stated: depends on normalization; artefacts and poor design bias results; no guidance on which module method is best (stability analysis recommended); undirected networks only.
- Not in this paper: module-preservation statistics (a later Langfelder 2011 paper); human/chimpanzee consensus (that is the 2007 eigengene paper, 18031580); pseudotime plots (hdWGCNA).
- Limitations for OUR design: correlations across units within a specimen are dominated by position itself, so modules will largely be positional programs (which is the point, but means module discovery and the PT axis share the same genes, a circularity). Module detection has many tunable parameters; stability analysis is needed.

Proposed: "The eigengene is the first PC of standardized member profiles; it weights members by how strongly they follow the dominant pattern, and its sign is fixed to agree with the module's mean expression. Because loadings are signed, it keeps members that move in opposite directions instead of cancelling them, but it shows only one pattern. The median weights members equally and is robust, but cancels opposing sub-trends."

## Fit to our design (2-4 lines, revised after reading the full text)
Useful for data-driven positional programs to set beside curated pathways, with eigengene curves along PT and kME to rank members. Treat module discovery as descriptive (many tuning parameters; run a stability check), restrict to genes held out from the axis where possible, and do not read significance from module-trait correlations computed over units.
