## What the paper actually does (from the full text)
- Model / statistic
  - Diffusion maps on PCs (adaptive anisotropic Gaussian kernel), multi-scale diffusion distance, kNN graph in that space. Pseudotime = shortest-path distance from a user-chosen start cell, refined iteratively by a weighted vote of max-min-sampled waypoints (Supp. Note 1).
  - Edges oriented by pseudotime (backward edges kept only within the cell's kernel scale) -> Markov chain -> terminal states = diffusion-component extremes that are outliers of the stationary distribution -> absorbing chain -> branch probabilities B = (I - Q)^-1 R; differentiation potential = entropy of B (Supp. Note 1, eqs 14-24).
  - Gene trends (Supp. Note 2; main text "The Palantir Algorithm"; Supp. Fig. 3): for each lineage, a GAM with a cubic-spline smooth of pseudotime, fit to MAGIC-imputed, log-normalised expression of all cells with branch probability > 0, each cell weighted by its branch probability. Predicted at 500 equal pseudotime bins. The band is a standard deviation from a residual-based formula (eq. 26). Fit with the R gam package, default parameters. Gaussian, not a count model.
  - Trend clustering (Supp. Note 3): genes pre-selected by MAST differential expression between clusters; trends z-transformed and clustered with PhenoGraph (k = 150); clusters annotated by hypergeometric tests on MSigDB c5 GO BP, Hallmark and c2 canonical pathways (Supp. Fig. 13).
  - Change points: the point of maximal change in differentiation potential (and in the erythroid branch-probability trend) is located with the second derivative of the trend (Supp. Notes 3-4; Supp. Fig. 15b,d).
- Null / calibration / significance: none for trends. No test of trend significance; P values only from MAST (between clusters) and hypergeometric GO tests. Cells are the observations.
- Replicates: three human bone marrow donors (~25,000 CD34+ cells) analysed separately. Reproducibility checked by projecting pseudotime and DP from replicate 1 onto replicates 2 and 3 through mutual nearest neighbours and correlating with de novo results (Methods; Supp. Figs 9-11); Fig. 3 analyses repeated on replicates 2-3 using replicate-1 gene lists (Supp. Fig. 14). No joint replicate model.
- Validation: robustness to waypoints, k, number of diffusion components and lineage subsampling (correlations mostly > 0.9; Supp. Figs 5-8); qualitative benchmark against Monocle 2, PAGA, DPT, Slingshot, FateID and single diffusion components on known marker trends (Supp. Fig. 17, Supp. Note 6); mouse hematopoiesis (2,700 cells) and mouse colon (1,811 cells; Tuft terminal state had to be set by hand).
- Plots: cells coloured by pseudotime, DP, branch probabilities on t-SNE of diffusion components; per-lineage gene-trend lines with SD bands (Fig. 2f, Supp. Fig. 3); trend-cluster panels with member trends and GO labels (Supp. Fig. 13); binned box plots of gene-set mean expression with DP overlaid (Fig. 3b-c).
- Software: Python `palantir` (github.com/dpeerlab/Palantir), Code Ocean capsule; trends via R gam (per Supp. Note 2).
- Limitations (authors): assumes unidirectional differentiation (fails for dedifferentiation, regeneration, cancer); needs the full range of intermediate states; time courses need explicit modelling. Limitations for us: trends are Gaussian GAMs on MAGIC-imputed data (imputation smooths and inflates gene-gene correlation); the band is a residual SD, not a replicate-level interval; no significance for trends.

## Fit to our design (2-4 lines, revised after reading the full text)
Fate probabilities, the Markov chain and terminal-state detection have no role on a single PT path. Transferable pieces are small: clustering z-scored trend curves, GO annotation of trend clusters, and fitting per replicate and comparing. Its trend model (Gaussian GAM on imputed data, residual SD band, no test) is weaker than our per-specimen NB curves.
