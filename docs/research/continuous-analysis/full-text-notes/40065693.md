## What the paper actually does (from the full text)
- Model / statistic: input = two datasets with independently inferred pseudotime (no integration). Gene expression is smoothed onto a user-set number of interpolated points with cellAlign's Gaussian-window method, the window shrunk where cells are dense (Methods 2.1). Dissimilarity matrix between interpolated points of the two trajectories (default 1 - Spearman; Euclidean or Pearson options) (2.2). Start and end points are chosen near the minimum-dissimilarity matches and extended toward the corners within a cut-off; DTW is run for every candidate start/end pair; path scores are bootstrapped and the path closest to the corners among those within min + mean(S) is kept (Algorithm 1). Matches whose dissimilarity is closer to the non-match threshold than to the match threshold are then cut, which allows divergence in the middle (2.3; Supp. Fig. S3). Pseudotimes of matched points and cells are then shifted onto a common axis (2.4).
- DE between conditions (2.5): sliding windows of matched interpolated points; cells are assigned to the nearest interpolated point; per window and gene, a Mann-Whitney U test on cells, log2FC as in Seurat v5; Bonferroni-adjusted P < 0.05 plus |log2FC| and detection filters (Supp. 1.4, 1.8).
- Null / calibration: none for the alignment (no permutation; the path is always found, and a warning is given if the median path dissimilarity is high; Results 3.1). DE P values treat cells as independent observations; no FDR calibration on null data. Success was judged by number of DE genes and number of enriched GO terms (Results 3.2-3.3), which the authors themselves call a proxy.
- Replicates: biological replicates are aligned to each other first (T. brucei WT01 vs WT02 gave a near 1:1 alignment, Supp. Fig. S8; T-cell WT1 vs WT2 and KO1 vs KO2, Supp. Fig. S14), then the aligned conditions are compared. Replicates are not used as a variance source in any test.
- Validation: dyngen simulations: a WT vs knockout truncated trajectory, a diverge-converge pair, and a negative control with different networks (Fig. 1; Supp. 1.1). TrAGEDy recovered the truncation and the middle divergence; cellAlign and G2G did not (G2G returned 1:1 alignments). In the negative control TrAGEDy still produced a path (with high dissimilarity), while G2G correctly reported no common alignment (Results 3.1, Fig. 1C). Robust to the pseudotime method (Slingshot, Monocle 3, PAGA; Supp. Fig. S7). Real data: T. brucei WT vs ZC3H20 KO and mouse T-cell WT vs Bcl11b KO; more DE genes and GO terms than Seurat FindMarkers and tradeSeq conditionTest, and far faster than tradeSeq.
- Plots: dissimilarity heatmap with the alignment path and cut matches (Figs 1, 2A, 3A); before/after alignment connection plots (Figs 2B, 3B); Venn and UpSet of DE genes per window (Figs 2C-D, 3C-D); log2FC heatmap per window (Figs 2E, 3E); tradeSeq smoother plots on the aligned axis (Supp. Figs S11, S17).
- Software: R, https://github.com/No2Ross/TrAGEDy; Zenodo 10.5281/zenodo.13310931.
- Limitations stated: TI is an approximation; gaps in pseudotime break the method (outlier cells had to be removed); window size and number of interpolated points must be tuned (Supp. 4). Limitations for OUR design: cell-level Wilcoxon tests are pseudoreplicated; no null for "partial" or "divergent" alignment calls; level is not separated from shape (Spearman dissimilarity is rank-based across genes, which partly removes level).

## Fit to our design (2-4 lines, revised after reading the full text)
Useful only if human and mouse PT axes cover different extents (partial alignment) or diverge in the middle. Its replicate-vs-replicate alignment is a good idea to copy as an empirical baseline (mouse 1 vs mouse 2 warp) before reading any human-vs-mouse or IR-vs-control warp. Its DE test is cell-level and should not be used.
