## What the paper actually does (from the full text)
- Model / statistic: trajectory inference (19 dynverse methods: Monocle 3, Slingshot, PAGA, ElPiGraph ...; Table S1) -> user picks a root-to-leaf path -> genes summarised per "key segment" between root/branching/leaf milestone nodes by mean normalised expression, ROGUE entropy-reduction score, or change rate (slope of a linear fit vs pseudotime after z-score filtering) (Methods "Summarizing gene expression levels along a path"). Paths with fewer than 3 segments are split at pseudotime quantiles (1 segment -> thirds; 2 segments -> halves) so STEM has at least 3 "time points". STEM then converts values to log ratios vs the first point, assigns each gene to one of a pre-computed set of model profiles, and groups similar significant profiles into clusters (Methods "STEM clustering").
- Null / calibration / significance: permutation test per model profile (number of genes assigned vs randomised temporal data), "assigns a p-value to clusters" (Abstract; Background; Methods). GO enrichment per cluster with STEM's built-in GO tool. Paths compared by hypergeometric overlap of cluster gene sets (Methods "Comparison of clustering results in different paths"; Fig. 5).
- Replicates: none; cells pooled per segment; real time points used only to root the tree (Discussion).
- Assumption: expression changes linearly between milestone nodes; checked by F-tests, >50% of genes on internal edges fit a line, terminal edges less (Discussion; Fig. S11).
- Validation: three scRNA-seq time series (human fetal immune, 103,766 cells, 18 time points; mouse embryonic blood, 42,262 cells; neural crest, 22,283 cells), 3,000-5,000 prefiltered genes; benchmark on one NK path (3,000 genes, 4,058 cells) by "NK gene ratio" vs scHOT, tradeSeq, Monocle 3 (scSTEM 5.98%, others 0-3.72%); dyntoy simulations (linear, bifurcating, multifurcating; 10,000 cells, 3,000 genes; 10/30/50% DEGs): all genes in significant clusters were simulated DEGs, some DEGs missed (Additional file 2 note, Fig. S12).
- Plot types: trajectory with highlighted path, STEM profile plots per cluster, top-10 GO bar plots per cluster (Fig. 2-4); cross-path cluster-overlap panels (Fig. 5A); per-gene profile panels (Fig. S9).
- Software: R Shiny GUI with modified STEM Java program, https://github.com/alexQiSong/scSTEM (MIT).
- Limitations the authors state: depends on trajectory inference quality and direction; too many branches hurt; prefiltering to a few thousand genes recommended; linearity between milestones assumed.
- Limitations for OUR design: on an unbranched PT axis scSTEM reduces the coordinate to 3 quantile bins, i.e. a discrete method as coarse as S1/S2/S3; cells (units) are pooled with no specimen model; significance is gene-count enrichment of profiles, not a per-gene test.
