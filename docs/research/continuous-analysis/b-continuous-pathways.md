# Part B: continuous pathway / gene-set analysis along pseudotime, pseudospace or time

Scope: how genes are combined into pathways when the axis is continuous, how pathway dynamics are tested,
how WHERE a pathway changes is reported, and which figures are used. All PMIDs were checked with
`lit.py summary` on 2026-10-14 (title, year and journal match). Items without a PMID give the URL or DOI
that was actually opened. Details were then checked against the full text of each paper on 2026-10-14. The
per-paper notes are in `full-text-notes/`, and each citation in the table carries its read status in brackets.
Not read in full: Zaslaver 2004, Hotspot and cellAlign (abstract only; Hotspot and cellAlign described from docs and code), Tirosh 2016 (methods supplement not accessible), maSigPro 2006 (web summary only), tcgsaseq, GeneSwitches, Neufeld and Phoenix (preprint only), Chechik & Koller 2009 (authors' long version).

Our current practice, for reference: per-specimen NB spline curves per gene; pathway "program" curve = median
of member genes' centred curves; peak-sorted heatmaps; logistic edge fits (position + 10-90% width);
limma cameraPR on gene-level positional statistics; human-vs-mouse and AKI-vs-control curve comparisons.

The random time trends are per gene, not per patient (a per-patient random trend is only an option in the package). One likelihood-ratio test covers the fixed and random time effects together (mixture chi-square null). The test is self-contained, and heterogeneity among members alone makes a set significant. ## (b) Ideas we could adopt (method, then the figure it produces)

1. **Position-set enrichment and a pathway timeline (PSEA on a line + GeneSwitches + Pseudotimecascade).**
   Inputs:
   - From the logistic and peak fits we already have, take each positional gene's edge or peak position per specimen. Chechik & Koller 2009 defined onset as the time to half of the peak, because it was more stable than the fitted midpoint; the same half-amplitude position suits our edges.
   - Per pathway, test the members' position distribution against the background of positional genes, using KS or Anderson-Darling. Chechik & Koller 2009 compared each GO category's onsets with those of its sibling categories (Wilcoxon); the sibling background is a useful alternative to all positional genes.
   - Build the null from random sets of the same size drawn from genes matched on expression level and panel availability, as PSEA does with its empirical background. This null treats members as independent draws, so it does not correct for correlation among members. Calibrate the final call at specimen level (agreement across specimens, or our balanced relabeling) rather than trusting the random-set P value.
   - Run the test per specimen and require agreement across specimens. Alternatively, bootstrap specimens to get a CI on the pathway's median position.

   Shift version: compute the per-member difference (human position minus mouse position, or AKI minus control) and test median shift = 0 against the background shift distribution. PSEA ran its test on per-gene phase differences in the same way.

   Figure: a ridgeline "pathway timeline".
   - One ridge per pathway (density of member edge positions), sorted by median.
   - S1/S2/S3 label boundaries drawn as background bands.
   - Specimen medians shown as dots.
   - Paired ridges for human and mouse, plus a side forest plot of the median shift with its specimen-bootstrap CI.

   This answers WHERE, not only WHETHER, and it is less affected than shape tests by "almost every PT gene is positional".

2. **Show the sub-trends inside a pathway before summarizing it (TcGSA, plus decoupleR `ulm` as the activity statistic).**
   - Within each pathway, cluster the members' centred curves; use the gap statistic and allow 1 to 3 clusters.
   - Report each sub-trend's median and its share of members.
   - Flag pathways where the median curve's amplitude is clearly smaller than the sub-trend amplitudes. Those are pathways where the current program curve cancels itself out.
   - PCA-maSigFun (row 2) is a published version of this check: a PCA per pathway, with signed loadings that show which members move in opposite directions.
   - For a single activity curve, use the `ulm` t-value per specimen-by-bin on centred profiles (members versus the other genes) as a score only, since its p-value assumes independent genes. Or use the PLAGE eigengene: its signed weights keep rising and falling members instead of cancelling them, so it is a direct check on the median. Compute it per specimen and orient its sign by its correlation with the median curve.
   - Formal option: a TcGSA-style mixed model. Model the centred log expression of members as a spline in position (fixed effect) plus gene-specific random spline effects, with specimen as a fixed effect, and calibrate it by our existing relabeling control. Random specimen variance cannot be estimated from 2 specimens. With units as observations the TcGSA test is pseudoreplicated, so the relabeling calibration is required, not optional. Its test is self-contained and would call nearly every PT pathway, so use the model to describe sub-trends, not to select pathways.

   Figure: a TcGSA-style heatmap of sub-trends along PT, with rows = pathway x sub-trend, row annotations for n members, direction and between-specimen correlation, and an inset spaghetti plot of members for a few heterogeneous pathways.

3. **Smooth positional programs learned across specimens and species, then annotated (MEFISTO, or TEMPTED).**
   - MEFISTO setup: groups = specimens or species, covariate = PT coordinate, input = normalised unit expression (Gaussian likelihood; residuals or VST, since there is no NB model or offset).
   - Run MEFISTO twice. Without warping, to compare where programs change in human and mouse on the shared PT coordinate. With warping (mouse as reference, positions binned), only to estimate a global human-to-mouse map; read the overall shift from the warp, not from the factors.
   - Each output factor has a smooth positional curve per group, a group-by-group correlation matrix with one "sharedness" score, and gene weights. There is no test for group differences, so "changed in AKI" stays descriptive.
   - Group-wise centring removes level differences, so only shapes are compared; AKI level changes vanish too.
   - Annotate the weights afterwards with set enrichment (MOFA2's enrichment, or cameraPR on the weights).
   - TEMPTED alternative: a specimen x gene x position tensor. Its specimen loadings capture amplitude or sign differences of a shared shape, not position shifts, and every gene must be measured in every specimen.
   - Use only measured orthologs (a gene unmeasured in one species gives that species no information on it), and preferably genes held out from building the PT curve, so the factors do not simply relearn the axis.

   Figure:
   - One panel per factor: curves along PT coloured by specimen.
   - A group-correlation heatmap per factor, with its sharedness score.
   - A ranked gene-weight strip with the enriched sets.
   - For TEMPTED, a specimen-loading plot.

4. **Positional information of a pathway (Dubuis/Tkačik/Petkova, with Phoenix-style decoding against random gene sets).**
   - For each pathway, decode PT position from its members' unit-level expression. Use either a Gaussian decoder (a per-position mean and a regularized covariance, following Tkačik 2015) or a random forest as in Phoenix.
   - Train on one specimen and test on the other. This is our adaptation; Phoenix cross-validates over cells within one data set.
   - Train on mouse and test on human only with level-free features (within-specimen standardized or ranked expression). Probe panels shift levels, and the decoder depends on absolute levels (Petkova 2019).
   - Report decoding error, the positional-error curve sigma_x(x), and transfer accuracy against random gene sets of the same size, matched on expression level.
   - Report bits only with the finite-sample bias correction Dubuis and Tkačik use. Plug-in joint bits for tens of genes are strongly biased upward, so prefer cross-validated decoding error.
   - Bits and sigma_x(x) are relative to the reconstructed coordinate, not to anatomy. In the embryo papers the noise is variability across embryos at a known position; ours would be unit-to-unit noise within a specimen. Say so.
   - Registration of the axis across specimens changes the answer (in Tkačik 2015, aligning embryos by a shift added about half a bit).
   - Compare each pathway's information with what the S1/S2/S3 labels carry about the same coordinate, estimated from the same units (at most log2 3 = 1.58 bits). Also compare it with the pathway's own expression cut into 3 levels at information-maximizing thresholds, as Dubuis did with an on/off code.
   - Use genes not used to build the PT curve (gene splitting, which Neufeld 2023 shows is valid). Count splitting is valid only for Poisson counts; for our high-count NB units it drifts toward double dipping. Training on one specimen and testing on another does not remove circularity if the test specimen's positions come from projecting its own counts (Neufeld Sec. 3.3), so held-out genes are needed in both specimens.

   Figure:
   - sigma_x(x) curves along PT for the leading pathways (lower = more precise), with label bands.
   - A dot plot of information per pathway with reference lines at the labels' measured information and at log2 3.
   - A small matrix of cross-specimen (and, with level-free features, cross-species) transfer accuracy.

5. **Change-point density and temporal enrichment (Trendy + Pseudotimecascade).**
   - From the existing edge positions and widths, build a transcriptome-wide breakpoint density along PT, and a density per pathway.
   - Edges alone miss genes with one gradient across the whole PT, and so do Trendy's breakpoints. Report the share of such genes beside the track; they change everywhere but have no edge.
   - Test whether breakpoints concentrate at the S1/S2 and S2/S3 label boundaries more than in a smoothed or permuted background. A pile-up at the boundaries does not by itself mean labels suffice, because a steep but graded edge gives the same pile-up. Pair it with a per-gene step-versus-smooth model comparison.
   - Order positional genes by edge position, slide a window (for example 50 genes, step 10), and run set enrichment in each window.
   - Window within each direction class (rising, falling, peaked), as Pseudotimecascade does, so rising and falling genes that switch at the same place are not pooled. Pseudotimecascade's default is 20% of a class per window, with a 10% step.
   - Split by edge width (sharp versus gradual).

   Figure: one shared PT x-axis with three stacked tracks:
   - breakpoint density with the label boundaries, plus the share of single-gradient genes;
   - a temporal-enrichment heatmap of pathways x window centre, coloured by -log10 FDR;
   - a sharp/gradual rug.

6. **Set-level decomposition of comparisons: mean shift, trend change and alignment (Lamian + Genes2Genes).**
   - Classify each gene as mean-shift, trend-difference or both, as Lamian does, for both human vs mouse and AKI vs control.
   - Summarize each pathway as the fractions of its members in each class. Lamian itself is gene-level; the set fractions are our extension.
   - Add G2G aggregate alignment over the members to show where along PT the pathway matches or diverges.
   - Standardize member curves within species first, because G2G scores level differences as mismatches. Treat warps in flat stretches as uninformative, and compare against mouse-to-mouse alignments as a null.

   Figure:
   - Lamian's six-panel heatmap for each lead pathway (raw per group, fitted per group, trend difference, mean shift).
   - A stacked bar of member classes per pathway.
   - An aggregate-alignment bar (match, warp, mismatch) along PT under the heatmap.

## (c) Gaps: what nobody seems to have done

- **No set-level test fits our design.** We need a reconstructed (estimated) axis, few specimen replicates, NB counts and species-specific gene universes all at once. TcGSA and tcgsaseq assume a known time axis and several subjects. Both are also self-contained, which along PT answers a question we do not need ("does the set change at all"). FUNNEL tests each subject separately and combines the P values by Fisher's method, but it needs dense curves per subject on log-scale data. Lamian is gene-level. It runs with few samples by constraining the sample covariance, but its smallest published design is 4 vs 4 and its permutation null is untested at 2 vs 2. The single-cell pathway tools (AUCell/UCell plus GAM, SCPA, Phoenix, GeneSwitches) treat cells as replicates.
- **Position enrichment on a linear axis lacks a correlation-aware, replicate-aware null.** PSEA is circular and relies on random-set backgrounds that treat members as independent. Chechik & Koller 2009 did test category onsets against sibling categories on a linear time axis, but with genes as independent observations and no replicates. GeneSwitches gives a median plus a hypergeometric test with no uncertainty. Pseudotimecascade gives per-gene switch-point CIs but no set-level CI or calibrated test of a pathway's position shift between conditions.
- **Uncertainty in the axis itself is not carried into set-level timing.** No method we found propagates position uncertainty (curve fit, projection error) into a pathway's position or width. switchde's authors warn that treating pseudotime as fixed may inflate the FDR. Lamian's cell bootstrap inside its permutation is the nearest step, and it is gene-level.
- **Set-level "sharp versus gradual".** We found no method that classifies a pathway by the width distribution of its members' transitions. The tools stop at gene-level edge or impulse parameters.
- **Cross-species set tests with different probe panels.** We found no method that explicitly handles pathway members measured in one species but not the other. TEMPTED and hdWGCNA's projection need the genes measured in both data sets, and MEFISTO tolerates missing values but learns nothing about an unmeasured gene in that species. This affects both competitive and self-contained statistics, and set-level comparisons should be restricted to members measured in both species.
- **Circularity at set level.** Neufeld 2023 shows that any test computed on held-out counts or held-out genes inherits validity (Remark 4.1, Sec. 3.4). This covers set tests when every member is held out. What is missing is a set-level method for the case where a set's members helped build the axis, and an NB-valid split for high-count units (an NB count-splitting preprint by the same authors exists; only its title was checked).
- **Positional information in bits for adult tissue pathways.** The Dubuis/Tkačik framework is established for embryonic gap genes. Dubuis 2013 compared continuous gap-gene levels with an optimal on/off code (2.92 versus about 4.1 bits). We found no comparison against externally defined anatomical segment labels, and no application to transcriptomic pathways along an adult tissue axis such as nephron or liver zonation.
- **Pathway topology versus position.** Enzyme ordering in time has bulk precedents: Zaslaver 2004 (E. coli, abstract only) and Chechik 2008 (yeast, where both forward and backward orders occur). Halpern 2017 is the liver precedent: bile-acid enzymes peak in reaction order, shown descriptively, while its formal pair score measures discordance, not order. We found none along the nephron or PT.
