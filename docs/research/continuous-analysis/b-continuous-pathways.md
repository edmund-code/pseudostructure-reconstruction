# Part B: continuous pathway / gene-set analysis along pseudotime, pseudospace or time

Scope: how genes are combined into pathways when the axis is continuous, how pathway dynamics are tested,
how WHERE a pathway changes is reported, and which figures are used. All PMIDs were checked with
`lit.py summary` on 2026-10-14 (title, year and journal match). Items without a PMID give the URL or DOI
that was actually opened.

Our current practice, for reference: per-specimen NB spline curves per gene; pathway "program" curve = median
of member genes' centred curves; peak-sorted heatmaps; logistic edge fits (position + 10-90% width);
limma cameraPR on gene-level positional statistics; human-vs-mouse and AKI-vs-control curve comparisons.

## (b) Ideas we could adopt (method, then the figure it produces)

1. **Position-set enrichment and a pathway timeline (PSEA on a line + GeneSwitches + Pseudotimecascade).**
   Inputs:
   - From the logistic and peak fits we already have, take each positional gene's edge or peak position per specimen.
   - Per pathway, test the members' position distribution against the background of positional genes, using KS or Anderson-Darling.
   - Build the null from random sets of the same size drawn from genes matched on expression level and panel availability. This is PSEA's empirical background, and it partly absorbs inter-gene correlation.
   - Run the test per specimen and require agreement across specimens. Alternatively, bootstrap specimens to get a CI on the pathway's median position.

   Shift version: compute the per-member difference (human position minus mouse position, or AKI minus control) and test median shift = 0 against the background shift distribution. This is PSEA's perturbation mode.

   Figure: a ridgeline "pathway timeline".
   - One ridge per pathway (density of member edge positions), sorted by median.
   - S1/S2/S3 label boundaries drawn as background bands.
   - Specimen medians shown as dots.
   - Paired ridges for human and mouse, plus a side forest plot of the median shift with its specimen-bootstrap CI.

   This answers WHERE, not only WHETHER, and it is less affected than shape tests by "almost every PT gene is positional".

2. **Show the sub-trends inside a pathway before summarizing it (TcGSA, plus decoupleR `ulm` as the activity statistic).**
   - Within each pathway, cluster the members' centred curves; use the gap statistic and allow 1 to 3 clusters.
   - Report each sub-trend's median and its share of members.
   - Flag pathways where the median curve's amplitude is clearly smaller than the sub-trend amplitudes. Those are pathways where the current program curve cancels itself out.
   - For a single activity curve, use the `ulm` t-value per specimen-by-bin on centred profiles (members versus the other genes), or the PLAGE eigengene as a sensitivity check.
   - Formal option: a TcGSA-style mixed model. Model the centred log expression of members as a spline in position (fixed effect) plus gene-specific random spline effects, with specimen as a fixed effect or calibrated by our existing relabeling control. Random specimen variance cannot be estimated from 2 specimens.

   Figure: a TcGSA-style heatmap of sub-trends along PT, with rows = pathway x sub-trend, row annotations for n members, direction and between-specimen correlation, and an inset spaghetti plot of members for a few heterogeneous pathways.

3. **Smooth positional programs learned across specimens and species, then annotated (MEFISTO, or TEMPTED).**
   - MEFISTO setup: groups = specimens or species, covariate = PT coordinate, warping turned on so the human axis is aligned to the mouse axis.
   - Each output factor has a smooth positional curve per group, a "sharedness" between human and mouse (or control and AKI), and gene weights.
   - Annotate the weights afterwards with set enrichment (MOFA2's enrichment, or cameraPR on the weights).
   - TEMPTED alternative: a specimen x gene x position tensor whose specimen loadings separate species or condition.
   - Use only measured orthologs, and preferably genes held out from building the PT curve, so the factors do not simply relearn the axis.

   Figure:
   - One panel per factor: curves along PT coloured by specimen.
   - A sharedness or group-covariance heatmap.
   - A ranked gene-weight strip with the enriched sets.
   - For TEMPTED, a specimen-loading scatter.

4. **Positional information of a pathway (Dubuis/Tkačik, with Phoenix-style decoding across specimens).**
   - For each pathway, decode PT position from its members' unit-level expression. Use either a Gaussian decoder (a per-position mean and covariance, following Tkačik 2015) or a random forest as in Phoenix.
   - Train on one specimen and test on the other; then train on mouse and test on human.
   - Report mutual information in bits, the positional-error curve sigma_x(x), and transfer accuracy against random gene sets of the same size.
   - Compare each pathway's bits with the 1.58-bit ceiling of S1/S2/S3 labels.
   - Use genes not used to build the PT curve, or count splitting (Neufeld 2023), to avoid circularity.

   Figure:
   - sigma_x(x) curves along PT for the leading pathways (lower = more precise), with label bands.
   - A dot plot of bits per pathway with a reference line at log2 3.
   - A small matrix of cross-specimen and cross-species transfer accuracy.

5. **Change-point density and temporal enrichment (Trendy + Pseudotimecascade).**
   - From the existing edge positions and widths, build a transcriptome-wide breakpoint density along PT, and a density per pathway.

   - Order positional genes by edge position, slide a window (for example 50 genes, step 10), and run set enrichment in each window.

## (c) Gaps: what nobody seems to have done

- **No set-level test fits our design.** We need a reconstructed (estimated) axis, few specimen replicates, NB counts and species-specific gene universes all at once. TcGSA and tcgsaseq assume a known time axis and several subjects. Lamian is gene-level and wants more samples. The single-cell pathway tools (AUCell/UCell plus GAM, SCPA, Phoenix, GeneSwitches) treat cells as replicates.
- **Position enrichment on a linear axis lacks a correlation-aware, replicate-aware null.** PSEA is circular and relies on random-set backgrounds. GeneSwitches gives a median plus a hypergeometric test with no uncertainty. Pseudotimecascade gives per-gene switch-point CIs but no set-level CI or calibrated test of a pathway's position shift between conditions.
- **Uncertainty in the axis itself is not carried into set-level timing.** No method we found propagates position uncertainty (curve fit, projection error) into a pathway's position or width.
- **Set-level "sharp versus gradual".** We found no method that classifies a pathway by the width distribution of its members' transitions. The tools stop at gene-level edge or impulse parameters.
- **Cross-species set tests with different probe panels.** We found no method that explicitly handles pathway members measured in one species but not the other. This affects both competitive and self-contained statistics, and set-level comparisons should be restricted to members measured in both species.
- **Circularity at set level.** Count splitting (Neufeld 2023) handles gene-level tests along an axis estimated from the same counts. We found no guidance for gene-set tests or pathway curves on such an axis.
- **Positional information in bits for adult tissue pathways.** The Dubuis/Tkačik framework is established for embryonic gap genes. We found no application to transcriptomic pathways along an adult tissue axis such as nephron or liver zonation, and no comparison against the information carried by discrete segment labels.
- **Pathway topology versus position.** "Just-in-time" enzyme ordering has bulk time-course precedents (Zaslaver 2004, Chechik 2008) and a liver precedent (Halpern 2017's discordant enzyme pairs). We found none along the nephron or PT.
