## What the paper actually does (from the full text)
- Model / statistic: input is a list of cycling transcripts (called rhythmic beforehand, e.g. JTK_CYCLE q < 0.05) with their peak phases, plus a GMT gene-set library. Three steps (Methods, "The PSEA algorithm"): (1) a Kuiper test (sum of the largest positive and negative ECDF discrepancies, invariant to where the cycle starts) of the set's phases against a uniform background and, separately, against the empirical phase distribution of all other cycling transcripts; (2) the circular (vector) mean of the set: its angle is the set's timing, its length measures cohesion (a small length with a significant test means multi-modal clustering); (3) leave-one-out: drop each gene and recompute the Kuiper statistic, so genes that drive the clustering are ranked. Sets with fewer than 5 rhythmic genes are skipped (Case study 1).
- Null / calibration: an empirical null for the Kuiper statistic made by drawing test sets of the same size from either the uniform distribution or the empirical phase distribution of the whole data set ("Java implementation"); adaptive number of draws (100, then 1,000, then x10). FDR by Benjamini-Hochberg. The draws are independent phases, so the null treats members as exchangeable independent draws: there is no model of inter-gene correlation and no use of replicate samples. The unit is the gene.
- Phase shifts (Case study 2): PSEA is run on per-gene phase differences (restricted feeding minus ad libitum, genes cycling in both). The Methods argue that for shifts a sensible null is "no shift" rather than uniform, which motivates the non-uniform background option, but the case study states only that settings were "the same as for case study 1". Anabolic versus catabolic set shifts were compared with a circular ANOVA (p < 0.001).
- Replicates: none modelled. Phase estimates are taken as fixed; their uncertainty is not propagated.
- Validation: simulation with von Mises sets (N = 10-50, varying mean and concentration): the KS test's power swings with the set's mean phase on a circle, the Kuiper test is uniformly powerful (Supp. Figs 1-3). Binning into 2, 4, 6 or 12 windows plus Fisher's exact test was weaker than Kuiper everywhere tested, and missed sets centred near bin boundaries (Supp. Figs 4-5). Four real case studies (12-organ circadian atlas; restricted feeding; exclusive CLOCK targets; HeLa vs U2OS cell cycle).
- Plots: per-set ECDF of member phases against the uniform CDF, with gene names sized by leave-one-out contribution (Fig 1A-B, Supp. Fig 6A); a circular summary placing each significant pathway at its vector-mean phase, font size = vector length (Fig 1C, Fig 5C-D); pathway x organ colour table of set phase (Fig 2); histograms of gene-level and set-level phase shifts (Fig 3); set-overlap Venn (Fig 5A-B). No rose plots.
- Software: Java 1.6 application; README says the package "is available upon request" (Additional File 10). No URL in the paper.
- Limitations (authors): MSigDB is human, so mouse genes were mapped to human homologs. Limitations for us: the test is circular (Kuiper); on a line the KS statistic is the natural analogue, and the KS power problem the paper shows is specific to circular data. Phases are point estimates; a gene-sampling null is anti-conservative when members are correlated; no replicate unit.

## Fit to our design (2-4 lines, revised after reading the full text)
A clean template for "where" enrichment: test member positions against a background distribution, report a set location (mean) and a cohesion score, and rank driver genes by leave-one-out. On a line use KS/AD rather than Kuiper. Its null is gene-level and ignores correlation and replicates, so for us it must be wrapped in specimen-level calibration. Its binning benchmark is a small, citable argument that discrete windows miss sets near window edges.
