# Legacy notebooks

`legacy/notebooks/` preserves the former cross-species and earlier mouse workflows for provenance.
They are **not supported**, do not share the current data contract, and may reference retired
paths, results, or statistical approaches.

Use the active `analysis/` workflow for all new work. If a legacy result needs to be reproduced,
create an isolated data environment and document the exact commit, inputs, and rationale rather
than mixing its outputs with `mouse_only_v5`.
