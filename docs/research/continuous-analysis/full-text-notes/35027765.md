## What the paper actually does (from the full text)
- Model / statistic: multi-view, multi-group sparse factor analysis (MOFA framework), Y^{m,g} = Z^g W^{mT} + noise. Each factor k has a Gaussian-process prior along a continuous covariate (1-D time or 2-D space): z = f_k(c) + eta, kernel = group kernel K^G_k(g,h) x squared-exponential covariate kernel (scale s_k, lengthscale l_k) (Methods "MEFISTO model"; Supp. 2.2-2.4). Weights are shared across groups (same molecular signature in every group; Supp. 8.2). K^G_k is a low-rank (R = 1 or 2, "depending on the number of groups") plus diagonal covariance, converted to a correlation matrix (Supp. 2.3, eq. 13). The underlying multi-group model "centers the features in each group to remove group-specific offsets" (Supp. 2.1, describing MOFA+ which MEFISTO extends).
- Smoothness score per factor = s_k in [0,1]. "Sharedness" = one score per factor, "the mean absolute distance to the identity covariance matrix in the off-diagonal elements" of K^G_k (1 = shared, 0 = not shared) (Methods "Downstream analyses"; Supp. 6.1). The per-factor group-group correlation matrix is the finer output (Fig. 2e; Supp. Fig. 12).
- Alignment: optional DTW in the latent space interleaved with the variational updates; monotone warping of each group to a user-chosen reference group; partial matching (different start/end) by default; can align classes of groups (e.g. species) instead of individual groups (Methods "Alignment"; Supp. 5). Needs a 1-D covariate with unique values per group, or averages samples that share a covariate value (Supp. 5, eq. 91).
- Null / calibration / significance: none for smoothness, sharedness, group kernels or warps (point estimates from variational inference + grid search on lengthscale, L-BFGS-B for the rest; Supp. 3.2.2). Feature-set enrichment on weights uses MOFA2's parametric t-test with BH (Ext. Data Fig. 3a, 6c; Supp. Fig. 8c, 16); GSEA on RNA weights (Fig. 4g); one-sided Wilcoxon for taxa (Fig. 3c).
- Replicates: groups can be individuals (43 infants in the microbiome case), species (5 in evo-devo) or conditions. Groups are modelled through the factor-wise group correlation matrix; there is no test of differences between groups or conditions.
- Likelihood: Gaussian by default; Poisson and Bernoulli available via Gaussian approximations (Supp. 8.1). For sequencing counts the authors recommend preprocessing (log, DESeq2 VST, or deviance/Pearson residuals) and a Gaussian likelihood (Methods "Data preprocessing"; Supp. 8.1). No negative binomial, no exposure offset. Evo-devo input was DESeq2 VST on library-size-corrected counts.
- Validation: simulations from the generative model (10 repeats; base 5 groups, 20 time points, 4 views x 500 features; varied time points, groups, missingness) vs MOFA (Fig. 1c,d; Ext. Data Fig. 1); alignment simulated with 3 groups and linear/exponential/identity warps (Supp. Fig. 1-3); real data: evo-devo atlas of 5 species x 5 organs, 7,696 orthologous genes, 14-23 stages per species, stage correspondences learnt by the model (Fig. 2; Supp. Fig. 6-7 compares learnt with published correspondences against mouse stages); infant microbiome (43 infants, 24 months); scNMT-seq gastrulation with UMAP as 2-D covariate; Visium mouse brain (2,696 spots, 1,000 inducing points).
- Plot types: factor values vs (inferred) covariate per group with GP mean and variance, smoothness and sharedness bars on top (Fig. 2d); group correlation heatmaps per factor (Fig. 2e; Supp. Fig. 12); variance-explained heatmaps per view and group (Fig. 2b); factor embeddings coloured by inferred time (Fig. 2c); before/after alignment plots (Ext. Data Fig. 2); top-weight gene plots and gene trajectories (Ext. Data Fig. 3-8); interpolation with 95% band (Supp. Fig. A.4).
- Software: MOFA2 (Bioconductor, v1.3.3) and GitHub bioFAM/MOFA2; also via Python muon; tutorials https://biofam.github.io/MOFA2/MEFISTO (Code availability).
- Limitations the authors state: no dedicated count/over-dispersion or zero-inflation noise model (Discussion); alignment removes overall timing differences between groups, so "this approach does not allow for any analysis of timing differences between groups" (Supp. 8.3); inducing points are "mainly sensible" with a single group or many samples per group (Supp. 4.1.4).
- Limitations for OUR design: (1) If warping is on, a human-vs-mouse position shift is absorbed into the warp and cannot appear in the factors; it must be read off the warp function, which has no uncertainty. (2) Group-wise centring removes specimen-level offsets: good for species panels, but AKI level changes vanish too (only shape remains). (3) Units need to be normalised outside the model (Pearson residuals with library size would match the authors' advice); our NB per-gene curves are not used. (4) Sharedness and group kernels are descriptive point estimates; with 2 mice per condition nothing calibrates "changed in AKI". (5) DTW needs binned positions per specimen.

## Fit to our design (revised)
A good exploratory tool: a PT-position GP per factor, specimens as groups, level offsets removed by group centring, factor-wise group correlations. Not inferential: no test of sharedness or of AKI change, no NB/offset, and warping must stay off for any human-vs-mouse position comparison. Recommendation 6 stands as exploratory, but its setup changes: alignment only to estimate a global warp, never while comparing positions.
