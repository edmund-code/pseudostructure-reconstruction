## What the paper actually does (from the full text)
- Statistic: a non-parametric covariance test (the class that includes HSIC and distance covariance). Expression y (centred, scaled) gives a projection kernel E = y(y'y)^-1 y'; coordinates S give Sigma = S(S'S)^-1 S'. T is the (scaled) trace of the product of the centred kernels; under H0 it follows a mixture of chi-squares, P by Davies' exact method (Methods "Method overview").
- Kernels: 11 - the untransformed coordinates (targets linear trends), 5 Gaussian-transformed and 5 cosine-transformed coordinate sets with parameters at the 20-100% quantiles of |coordinates|; 11 P values combined by the Cauchy rule (Methods; Supp. Fig. S17). Per-kernel counts in Table S3: the untransformed (linear) kernel finds many unique genes; cosine kernels add few.
- Covariates: replace the centring matrix with a projection off a covariate matrix X. Used for "conditional SE analysis" with RCTD cell-type compositions (Slide-seqV2) or assigned cell types (HDST): about half of SE genes lose significance after conditioning (518 -> 281; 66 -> 36), and "cell type-specific SE analysis" restricted to one cell type (Fig. 3; Supp. Figs. S8, S9, S11).
- No library-size offset is described: y is the gene's measurement, centred and scaled; normalisation would have to enter as a covariate.
- Calibration: null simulations with NB counts (moderate and high sparsity) and genomic inflation factors (Fig. 1E; Supp. Fig. S1); coordinate permutations of each real dataset (10x, or 1,000x for STARmap) (Methods "Real data analysis"). SPARK-X calibrated throughout. SPARK (Poisson PQL) failed to converge in sparse data (Table S2: 97.5% failures at 99.5% zeros; glm.nb fails 75%); SPARK-G inflated in sparse data; SpatialDE "overly conservative" at moderate sparsity and "unduly inflated" at high sparsity (Results "Simulations").
- Replicates: none; one section per dataset.
- Validation: simulations (hotspot, streak, gradient; n up to 50,000); Slide-seq cerebellum (2,336 SE genes at FDR 1%), Slide-seqV2 cerebellum (688), HDST olfactory bulb (125; only SPARK-X could run), Visium human heart (1,536 vs 644 for SPARK), Visium ovarian cancer, STARmap. Validation via Harmonizome, marker lists, Allen ISH.
- Plot types: runtime and memory curves (Fig. 1B-C); QQ plots under permuted null (Figs. 1E, 2A, 3B); power curves; spatial gene maps with P before/after covariate adjustment (Fig. 3D); layer x gene-cluster heatmap (Fig. 4C); GO bubble plots.
- Software: implemented in the SPARK R package (C++ via Rcpp), www.xzlab.org/software.html; code and data on GitHub and Zenodo (MIT licence) (Methods; Availability).
- Limitations (authors): only the projection covariance function was explored; other kernels might add power (Discussion). For OUR design: one sample; unit-level permutation; no offset; the test detects dependence, it does not estimate shape.

- c:57, What it adds ("could run on the 1-D pseudospace... only duplicates our positional F-test"; length scale and kernel classification carry over) - VERDICT: misses an important point. SPARK-X's conditional analysis (test for spatial pattern after projecting out discrete cell-type covariates; and the within-cell-type test) is a published, calibrated, gene-by-gene test of "spatial variation beyond discrete labels". On our axis this is exactly "positional signal beyond S1/S2/S3 labels" (labels as covariates) and "positional signal within one segment" (subset). It weakens the synthesis claim that no published method asks continuous-vs-discrete gene by gene. What stays new for us: specimens as replicates, an offset count model, and shape classes.

## Fit to our design (revised after reading the full text)
Moderate as a comparator, not as our main test. A SPARK-X run on the 1-D pseudospace with S1/S2/S3 labels (and specimen) as covariates is a cheap, published "beyond-labels" test that reviewers will recognise; it would need our specimen-level relabeling for calibration, since its permutation null treats units as independent and it has no library-size offset.
