## What the paper actually does (from the full text, via paraphrase)
- Model: GP regression per gene and condition, y_t = f(t) + noise with time-dependent noise variance. New non-stationary squared-exponential kernel with a length-scale that grows with time from a minimum at t = 0 (the perturbation time) to a maximum: l(t) = l - (l - l_min) exp(-c t). Hyper-parameters by maximising the marginal likelihood (L-BFGS).
- Noise / replicates: the time-dependent noise variance is not learned; it is "predefined for each gene ... by interpolating the empirical replicate variances" with splines. Replicates (3 per condition) enter only through this noise model; there is no replicate-level curve.
- Test: two hypotheses per gene: independent GPs for case and control vs one shared GP on pooled data. New ratio statistics evaluated at arbitrary times, not only at observed time points: the expected marginal log-likelihood ratio (EMLL), using samples from the noisy posterior, and a noisy posterior concentration (NPC) ratio. A time is called differential when the log ratio exceeds a threshold (1.0; 1.5 also used). Contiguous supra-threshold stretches are the "differential time periods".
- Null / calibration: none. No P values and no FDR; the threshold trades precision against recall. The statistic has no sign (direction is not reported).
- Validation: simulation of 600 genes resampled from GPs learned on the real data, with perturbations added in random periods; AUC 0.89 for EMLL with the non-stationary kernel vs 0.77 (continuous) / 0.83 (observed points) for GPTwoSample (Stegle 2010). The non-stationary kernel improved the marginal log-likelihood over a stationary one. Real data: HUVEC endothelial cells, 2 Gy vs control, 8 time points (12 h to 21 days), 283 genes by TaqMan qPCR, 3 replicates; 77 genes at threshold 1.5 (174 at 1.0); maximum differential expression 8-12 days post-irradiation.
- Plots: posterior with 95% band and the learned length-scale function (Fig. 1); the three ratio tracks for one gene with called periods (Fig. 2); ROC curves (Fig. 3); number of differential genes along time (Fig. 4); heat-map "temporal cascade of differential expression time periods" for the 77 genes (Fig. 5); PANTHER pathway classes per time window (Fig. 6).
- Software: R package `nsgp`, from www.ibisc.fr/en/logiciels_arobas (as stated).
- Limitations: no formal error control; the kernel's non-stationarity is built around a perturbation at t = 0; noise from empirical replicate variances. For us: a spatial axis has no "t = 0 perturbation", so the kernel prior would need redesign; with 2 specimens per group the empirical variance used as the noise model is unstable; units within a specimen are not replicates.

## Fit to our design (revised after reading the full text)
The concept (two-condition GP likelihood ratio evaluated continuously along the axis to locate differing stretches) transfers; the implementation does not, because its kernel is anchored at a perturbation time and its noise model needs per-time replicate variances. For IR vs control, a specimen-level difference curve with a simultaneous band, calibrated by our balanced relabeling, gives the same "where" answer with error control that nsgp lacks.
