## What the paper actually does (from the full text)
- Model / statistic: per gene, NB-GAM (default) or ZINB-GAM of counts on a cell's inferred pseudotime T in [0,1], cubic spline with K = 6 fixed (mgcv, penalized REML). ZINB vs NB chosen by AIC (NB unless ZINB AIC is better by >= 10). Test statistic S_j is Wood's (2013) smooth-term statistic using a rank-r pseudoinverse of the covariance of the fitted f_j (Methods, "Statistical test and p-value calculation"). One lineage at a time. No library-size offset is described in the model text.
- Null / calibration: subsample 80% of cells without replacement, B = 1000 times by default (stratified within predefined cell groups if given); re-run the user's pseudotime method on each subsample; permute the subsample's inferred pseudotime across its cells; refit to get null values s_j^b. P-values: empirical ((#{s_j^b >= s_j}+1)/(B+1)) and parametric (fit Gamma and 2-component Gamma mixture by ML, choose by LRT with 3 df at p <= 0.01, right-tail p). Results use the parametric p (Methods). The observed statistic is computed once on the full data with the full-data pseudotime; coordinate uncertainty enters only through the null distribution. The bootstrap is explicitly rejected because repeated cells break some TI methods such as Monocle2 (Methods, "Uncertainty estimation"). Supplement: 50-90% subsampling gives similar p-values (Fig S22); 100 subsamples approximate 1000 (Fig S20); Anderson-Darling checks of the Gamma fit (Fig S21).
- Replicates: none. Cells are the observations; no sample or specimen term. Within-lineage only; no between-condition test (Discussion: restricted to DE within one lineage).
- Validation: dyntoy simulations (three single-lineage sets of 500 cells x 5000 genes, 20% DE, low/medium/high dispersion; one bifurcation set of 750 cells), Slingshot and Monocle3-PI pseudotime; comparators tradeSeq, Monocle3-DE, NBAMSeq, ImpulseDE2 (Fig 3, S3-S5). Real data: LPS dendritic cells (390 cells), beta-cell maturation (497), bone marrow (2660, two lineages), NKT cells (197, three lineages), iPSC cell cycle with 101 cyclic genes plus 101 shuffled null genes (888 cells). Only Monocle3-DE was roughly calibrated among competitors; tradeSeq, NBAMSeq and ImpulseDE2 p-values "much deviated" from uniform in simulation (Results, Fig 3a,b), and tradeSeq p-values were bimodal on every real dataset (Figs 4-7). Supplement attributes tradeSeq's conservativeness to using the nominal K-1 df instead of the effective df.
- Plots: subsample pseudotime spread per cell (Fig 2b,d), subsample topologies (Fig 2f, 6b), null p-value histograms and QQ plots incl. -log10 scale (Fig 3a,b; 8a,c), FDP, ROC and power bars, Venn diagrams, GO bar charts, per-gene NB-GAM fits on pseudotime (Fig 5e,j; S15-S18), UMAP gene plots.
- Software: R package PseudotimeDE, https://github.com/SONGDONGYUAN1994/PseudotimeDE (MIT); reproduction code at doi 10.5281/zenodo.4663580.
- Limitations stated: computational cost (3-8 h with 24 cores and 1000 subsamples); needs a topology that is stable across subsamples; not for many equivocal lineages; topology uncertainty not handled; choice of TI method left open.
- Limitations for OUR design: the null permutes the coordinate across cells, i.e. cells/units are exchangeable; it has no specimen level, so with several specimens it would reproduce the unit-level over-calling Lamian warns about unless permutation is restricted within specimens. It gives no intervals on curves, onsets or peaks, and no condition comparison.

- d-comparing-trajectories.md:27 (row text) - tests change along pseudotime (NB-GAM or ZINB-GAM); re-infers pseudotime on subsamples and permutes; null includes pseudotime-inference uncertainty; "tradeSeq, NBAMSeq and ImpulseDE2 p-values were badly miscalibrated"; "Within one condition only"; plots QQ and per-cell pseudotime spread; No (single sample) - VERDICT: correct. (Monocle3-DE was the one competitor that was roughly calibrated but less powerful; tradeSeq's miscalibration is bimodal, conservative on real data.)
- d-comparing-trajectories.md:27 (For us) - "Refit the elastic curve on bootstrap subsamples of units and carry that coordinate uncertainty into every AKI-versus-control and human-versus-mouse curve comparison" - VERDICT: misses an important point. The paper rejects the bootstrap and uses 80% subsampling without replacement. It has no between-condition test, and its null permutes the coordinate across cells, which ignores specimens.
  - Replacement: "Refit the elastic curve on 80% subsamples of units, drawn without replacement within each specimen (the paper rejects the bootstrap because duplicated cells break some trajectory methods). PseudotimeDE uses such refits only to build the null for a one-sample trend test, and its null permutes positions across cells. Using the refits for AKI-vs-control or human-vs-mouse comparisons would be our own extension, and any permutation must keep specimens, not units, as the unit."

## Fit to our design (2-4 lines, revised after reading the full text)
Useful only as a recipe for coordinate uncertainty: refit the elastic curve on within-specimen 80% subsamples and look at how unit positions move (their Fig 2b view). Its test is a unit-level, one-sample trend test with no specimen term, so it should not replace our specimen-level calibration. With 100 subsamples it is cheap enough to try as a sensitivity check on onset/peak positions.
