Read status: PREPRINT READ (arXiv:1605.02351v5, 6 Jan 2017, the version stating it was accepted in Biostatistics; not the typeset journal version. Europe PMC had only the abstract.)
Pages/sections read: all 24 pages - abstract, sections 1-7, software, supplementary sections S.1-S.3 with Fig. 6 (included in the arXiv file).

## What the paper actually does (from the full text)
- Model / statistic: data are log-CPM (eq. 1). Working model (eq. 2-4): a linear mixed model per gene set with gene-specific intercepts, covariates, gene-specific fixed time effects on K basis functions, gene-by-subject random time effects and random intercepts. H0: the mean of y does not depend on time for any gene in the set (self-contained). The variance-component score statistic Q = q'q (eq. 6-7), asymptotically a mixture of chi-square(1) variables with weights from the eigenvalues of Cov(q) (S.1). The working model need not hold; validity rests on the CLT over independent subjects. Heteroscedasticity: the variance of y is modelled as a smooth function of its mean by local linear regression, at gene level (eq. 20, preferred) or voom-style. A "homogeneous" variant assumes one shared trajectory for all genes in the set (2.2.1) and loses power when some genes rise and others fall.
- Null / calibration: asymptotic mixture-chi-square P value, or a permutation version for very small n that shuffles time labels within each individual (2.2.2), valid because under H0 a gene's observations in one individual are exchangeable across times. In practice Sigma_a and Sigma_xi were set to the identity (Section 5, 6).
- Replicates: subjects (individuals) are the independent units; the CLT is over subjects. At n = 6 subjects x 3 times the asymptotic test was highly deflated (type I error 0.001), so the permutation test is needed (5.3).
- Validation: synthetic data (n = 200, mis-specified mean model): gene-level variance modelling kept nominal type I error; voom-style weights deflated tcgsaseq (0.035) and inflated ROAST to 0.56 (5.1.1). Against ROAST, edgeR-ROAST and a DESeq2 min-P test (n = 50-150): tcgsaseq had the highest power; DESeq2-min did not control type I error (5.2). Realistic small-sample simulation (n = 6, 3 times, correlated sets of 30-400 genes): permutation tcgsaseq most powerful and at nominal level; also for heterogeneous sets (S.3, Fig. 6). Real data: 32 kidney-transplant patients, 4 time points, 9 transplant gene sets (3 significant vs 0 for voom+ROAST); Arabidopsis arenosa, 48 plants, 4 time points.
- Plots: power curves (Figs 1-4, 6); P-value dot plot per gene set (Fig 5). No curve or heatmap displays of set trajectories.
- Software: R package tcgsaseq on CRAN (https://cran.r-project.org/web/packages/tcgsaseq).
- Limitations (authors): time-varying covariates need extra assumptions; inter-gene correlation not modelled explicitly (could be added via a working correlation). For us: it is self-contained ("any gene in the set changes along the axis"), so on PT it would call nearly every set; it gives no effect size, shape or location, only a P value; with a reconstructed axis built from the same counts, a within-specimen position permutation is circular.

## Fit to our design (2-4 lines, revised after reading the full text)
Useful as a model for handling RNA-seq heteroscedasticity in a set-level score test, and its within-subject time permutation is a clean small-n idea. But it is self-contained and gives only "changes or not", which nearly every PT pathway will pass; it neither locates nor shapes the change. Not a recommendation driver for us.
