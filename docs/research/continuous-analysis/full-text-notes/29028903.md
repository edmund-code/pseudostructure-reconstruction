## What the paper actually does (from the full text)
- Benchmark of nine time-course (TC) DE tools (DyNB, EBSeq-HMM, FunPat, ImpulseDE2, lmms, Next maSigPro, nsgp [the MATLAB AdaptiveGP implementation], splineTimeR "splineTC", timeSeq) against "pairwise" edgeR/DESeq2 GLM likelihood-ratio tests that treat time points as categories.
- Simulation: NB counts with mean/dispersion pairs from 41 B-cell samples; 18,503 expressed genes; standard design = control and treatment TCs, 4 time points, 3 replicates; control held constant; 24 pattern categories x 50 genes = 1,200 DEGs, each pattern a change spanning 2 or 3 consecutive time points. Scenarios varied library size, replicates and time points; longer series were made by spline-interpolating the same patterns.
- Results, standard scenario at P < 0.01 (Table 2): pairwise F1 0.89 (FDR 0.06); ImpulseDE2 F1 0.88 (FDR 0.05); splineTC 0.83 (0.06); lmms 0.78 (0.11); maSigPro 0.67 (FDR 0.42); timeSeq 0.57 (0.50); DyNB 0.56 (0.44); FunPat 0.56 (0 FP, low sensitivity); nsgp 0.40 (0.60); EBSeq-HMM 0.19 (0.88). DyNB and nsgp were scored by taking the top 1,200 Bayes factors.
- Noise robustness (Fig. 2D): pairwise most stable, then ImpulseDE2, FunPat, splineTC.
- More replicates improved all tools; more time points boosted maSigPro (~30%, no false positives) and splineTC (~10%, then outperforming pairwise); ImpulseDE2 got worse with more time points (more false positives), which the authors attribute to the impulse shape not fitting the "stretched" simulated patterns; slow tools were not run on long series.
- Conclusions (verbatim sense): pairwise comparison "was the most robust and accurate approach on the standard experimental setup. The only exception was ImpulseDE2 that performed almost equally, but was more prone to noise." Discussion: ImpulseDE2 was "the overall best performing tool, achieving results comparable with the classical pairwise comparison approach, with a higher number of replicates even outperforming edgeR."
- Biological data: PIP3 signalling (GSE69822), 6 time points x 3 replicates; ImpulseDE2 and splineTC reproduced DESeq2's candidates.
- Replicate unit: biological replicates per time point (bulk).
- Software: scripts at github.com/daniel-spies/rna-seq_tcComp.
- Limits relevant to us: the simulated truth is a set of discrete changes at a few time points with a flat control, which favours categorical (pairwise) tests by design; "pairwise" here means time point vs time point, not a continuous axis; the main failure of most TC tools was false positives (calibration), not lack of power.

## Fit to our design (revised after reading the full text)
A useful caution about false positives in continuous time-course tools, and a reminder that a step-like truth favours categorical tests. It does not show that continuous models lose on densely sampled axes; it shows the opposite for 8+ time points. It supports keeping a direct, calibrated continuous-vs-label comparison (the proposed boundary-step model is the right control).
